# Сценарий ручной демонстрации «Часть 4 — сравнение и оптимизация»

> Назначение: показать куратору **часть 4** `ND/tasks/n_6/Задание.txt` в живом контуре:
> сравнение облачной и локальной генерации по **трём осям** (качество / скорость /
> стабильность), профили параметров модели, эффект оптимизации («до/после»), учёт ресурсов.
> Время: 15–25 минут (CPU-инференс — долго). Файл — артефакт процесса, живёт только в `dev/`.

## Реквизиты

- Терминал в корне проекта, venv активирует обёртка `./run.sh` сама.
- **LM Studio** `127.0.0.1:1234`, **Ollama** `127.0.0.1:11434` (bge-m3).
- Ключ облака в `.env` (`API_KEY`) — для оси cloud. Без ключа ось cloud пропускается.
- Индекс RAG построен (`./run.sh --rag-ingest`).

---

## Шаг 1. Сравнение генераторов: cloud vs local (три оси)

```bash
./run.sh --rag-gen-compare --gen-modes cloud,local \
  --gen-questions 3 --repeat 1 --gen-resources \
  --gen-report dev/logs_reports/stages/gen_compare_demo.md
```

**Увидите** отчёт с тремя осями:

| Ось | Метрики |
|---|---|
| **Качество** | `must_contain`, число источников, валидные ссылки |
| **Скорость** | медиана, p95 (мс), ток/с |
| **Стабильность** | число ошибок, согласованность |

Плюс — вердикт и разбор расхождений, ресурсы (RSS пик/среднее, CPU, RAM до/после).

> Ориентир из этапа 6 (`rag_local_compare.md`): cloud `must 0.6491`, медиана 22 764 мс;
> local `must 0.6316`, медиана 175 892 мс — **качество сопоставимо, локальная медленнее**
> (CPU без GPU), но **ошибок у локальной 0**.

## Шаг 2. Профиль параметров модели

```bash
./run.sh --rag-gen-compare --gen-modes local --gen-questions 2 --repeat 1 \
  --gen-profile rag-strict --gen-report dev/logs_reports/stages/gen_profile_demo.md
```

**Увидите:** сравнение с профилем `rag-strict` (temperature 0.1, max_tokens 700,
ctx 8192). Профиль **попадает в тело запроса** к модели (проверяется гейтом).

> Профили — в `models.json → profiles`; переключение `/model profile <name>`.

---

## Шаг 3. Замер «до/после» оптимизации

Готовый отчёт (этап 7/8): `dev/logs_reports/stages/optimize_before_after.md`.

```bash
sed -n '1,25p' dev/logs_reports/stages/optimize_before_after.md
```

**Увидите** (боевая 3B Q6_K):

| Ось | «До» (этап 7) | «После» (этап 8) |
|---|---|---|
| медиана | 247 682 мс | **58 975 мс** |
| `must_contain` | 0.5439 | 0.5 |
| RSS | — | ~3,98 ГБ |

> Что оптимизировали: локальный строгий шаблон `[rag]` (смягчён), профиль `rag-strict`,
> ранняя остановка. Скорость выросла в ~4 раза.
