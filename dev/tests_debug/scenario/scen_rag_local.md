# Сценарий ручной демонстрации «Часть 3 — полностью локальный RAG (retrieval + генерация)»

> Назначение: показать куратору **часть 3** `ND/tasks/n_6/Задание.txt` в живом контуре:
> **настоящий** корпус, **настоящие** локальные эмбеддинги (Ollama `bge-m3`),
> **настоящая** генерация локальной моделью (LM Studio, боевая 3B), блок `[rag]` в
> промпте со ссылками и проверка опоры ответа (grounding) — **без единого внешнего запроса**.
> Время: 10–15 минут (CPU-инференс). Файл — артефакт процесса, живёт только в `dev/`.

## Реквизиты

- Терминал в корне проекта, venv активирует обёртка `./run.sh` сама.
- **Ollama** слушает только `127.0.0.1:11434`, модель `bge-m3` подтянута.
  Проверка: `curl -s http://127.0.0.1:11434/api/tags`.
- **LM Studio** слушает `127.0.0.1:1234` (`lms server start`).
- Демо-пользователь — свежий (`demo`).
- **Офлайн-режим** (главное доказательство «полностью локально»): закрыть внешний доступ
  `export HTTPS_PROXY=http://127.0.0.1:1 HTTP_PROXY=http://127.0.0.1:1
  NO_PROXY=127.0.0.1,localhost`.

## Шаг 1. Индексация корпуса (одна команда)

```bash
./run.sh --rag-ingest
```

**Увидите:** дельту индексации и число чанков.

```
[RAG] Индексация завершена: +0 новых, ~0 изменённых, -0 удалённых, =9 без изменений
[RAG] Чанков в индексе: 117; эмбеддингов запрошено: 0; время: …s
[RAG] Индекс сохранён: …/rag/index
```

> Первый прогон: `+9 новых`, эмбеддингов ~117 (bge-m3). Повторный — `=9 без изменений`, 0
> эмбеддингов (инкрементальность).

## Шаг 3. Проверка «полностью локально» (внешний доступ закрыт)

```bash
export HTTPS_PROXY=http://127.0.0.1:1 HTTP_PROXY=http://127.0.0.1:1
export NO_PROXY=127.0.0.1,localhost
curl -s -o /dev/null -w "routerai=%{http_code}\n" https://routerai.ru/   # → 000 (облако недоступно)
curl -s -o /dev/null -w "ollama=%{http_code}\n"   http://127.0.0.1:11434/api/tags   # → 200
curl -s -o /dev/null -w "lmstudio=%{http_code}\n" http://127.0.0.1:1234/v1/models   # → 200
```

> `routerai=000` доказывает, что облако реально отрезано.

## Шаг 4. Полный локальный RAG в REPL: `--rag --local-gen`

```bash
./run.sh --rag --local-gen --user demo
```

В REPL задать 3–5 вопросов:

```
как запретить агенту менять технологический стек проекта
единый интерфейс для всех видов памяти агента
как устроен реестр моделей
какие инварианты есть у агента
/exit
```

**Увидите:**

- строку `[Генератор] --local-gen: RAG генерирует lmstudio/Qwen2.5-Coder-3B-…-Q6_K`;
- баннер `[Сессия] модель: lmstudio/… (локально, Q6_K, ctx 8192, профиль rag-strict)`;
- в промпте блок `[rag]` **после** `[tools]` и **до** `[long_term]`;
- ответ со ссылками `[doc_id#chunk_id]` + `[RAG] Источники ответа (N), опора: ok/partial/hallucination`;
- цитаты из чанков.

> **Без `--rag`** блок `[rag]` в промпт не попадает, `rag/` не импортируется вовсе
> (инвариант §5 мастер-плана).

> **Нюанс one-shot.** Флаг `--local-gen` действует в REPL-контуре. Для one-shot-ответа
> (`--rag-ask`) модель задаётся явно: `./run.sh --rag-ask "<вопрос>" --model <local-id>`.

## Шаг 5. Команды `/rag` (без LLM) и `/gen`

```
/rag status
/rag find как считается бюджет токенов промпта
/rag check Инварианты запрещают менять стек [<doc_id>#<chunk_id>].
/rag stats
/gen status
```

**Увидите:**

- `/rag find` — топ-5 со скорами (задаёт «последние источники» для `/rag check`);
- `/rag check` — вердикт grounding (`ok`/`partial`/`hallucination`), покрытие, ссылки;
- `/rag stats` — индекс, модель, размер, RAM, кэш, латентность p50/p95, состояние Ollama;
- `/gen status` — кто генерирует RAG (модель агента).

## Шаг 6. Grounding: ловим галлюцинацию

```
/rag check Метод предложили в 1994 году и он даёт точность 99.9% [<doc_id>#<chunk_id>].
```

**Увидите:** `Вердикт: hallucination`, `числа вне источников: 1994, 99.9`.

> В режиме `strict` при обычном ответе агента такая ситуация запускает **одну**
> авто-перегенерацию с фидбэком; при повторном провале — явная пометка в ответе.

## Ожидаемый итог

- Индекс строится одной командой, переживает перезапуск, обновляется инкрементально.
- **Ни одного внешнего запроса**: эмбеддинги Ollama + генерация LM Studio, всё на loopback.
- Блок `[rag]` в промпте со ссылками; без `--rag` промпт байт-в-байт прежний.
- Grounding ловит выдуманные числа; `TaskStage` не затронут.
