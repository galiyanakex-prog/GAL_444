## 2. Шаги этапа (исполняемый алгоритм)

### Шаг 0.1 — Активировать окружение и зафиксировать точку старта
1. `cd Nedela_4/den_16`; использовать venv недели (`../../.venv/bin/python`).
2. Зафиксировать дерево новых модулей: `ls core/tools.py core/tool_registry.py
   integrations/mcp/*.py`.

### Шаг 0.2 — Сверить факт с §0.3 плана-эталона
Составить таблицу «есть / нет»:
- **есть**: внутренняя модель, реестр, stdio-транспорт, client/gateway/provider/demo,
  конфиг/каталог в Store, `/mcp`-семейство, `--mcp`/`--mcp-probe`;
- **нет** (закрывается M1–M12): `HttpMCPTransport`; реальный endpoint; `call_tool`;
  `core/tool_executor.py`; `core/tool_policy.py`; tool-use в `llm_client`/`prompt_builder`/
  `agent`; блок `[tools]`; `/mcp call`; автотесты/документы под живой прогон;
  актуализация `arch_den_16.md`.

### Шаг 0.3 — Зафиксировать факты о реальном сервере (из §0.4 плана-эталона)
Записать в `migr_log.md` M0: protocol `2025-11-25`, `projecteol-weather v1.0.0`, 3 тула
(`search_locations` / `get_forecast_metadata` / `get_weather_forecast`) со схемами;
результат `call_tool("search_locations", {"query":"Москва"})` → Moscow RU (55.75204,
37.61781); SDK-квирки: `streamable_http_client`, атрибут `input_schema`.

### Шаг 0.4 — Зафиксировать точки внедрения (не менять)
`core/state_machine.py` (TaskStage 8, карта, API контроля), `core/invariants.py`,
`memory/*` (полностью), `storage/db.py`, базовые контракты `core/llm_client.py` и
`core/prompt_builder.py` (расширяются **только обратно совместимо**).

### Шаг 0.5 — Регрессионный baseline (без живого ключа)
```bash
PY="../../.venv/bin/python"
$PY -m py_compile Kod.py core/*.py memory/*.py storage/*.py integrations/mcp/*.py   # L1
env -u API_KEY $PY dev/tests_debug/unit_runner.py                                   # L2
API_KEY=test-key $PY dev/tests_debug/smoke.py                                       # L3
API_KEY=test-key $PY dev/tests_debug/scenario.py                                    # L4
API_KEY=test-key bash dev/tests_debug/check_acceptance.sh                           # гейт
```
**Ожидаемый результат:** L1 ok; L2 **112 OK, 0 FAIL**; L3 SMOKE OK (6); L4 **10/10**;
гейт **18 из 18**, exit 0.
