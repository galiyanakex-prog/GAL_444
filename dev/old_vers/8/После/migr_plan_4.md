# migr_plan_4.md — Этап 4. Субагенты на локальных LLM (L3)

> Рабочий план **одного этапа** на основе `dev/migr_plan.md` (**Ревизия 8, v1.1**, §4 «Этап 4»).
> Контур: **L (локальные LLM)**. Метка цели: **L3**. Зависимости: **этап 3**.
> Порядок: **пошагово с оператором**. **Коммиты — только за оператором** (ШАГ 4.6).

## Цель этапа

Часть 2 `Задание.txt`: «возможность поднимать **субагентов** (вспомогательные CLI-сессии),
работающих на локальных LLM, по команде **"сделай локально в `<llm-service>`"**».

## Предусловия (после этапа 3)

- `/model` и подпись модели работают; `ModelRegistry` строит клиент по `ModelSpec`.
- `Kod.py` — REPL с диспетчером команд; `--user`, `--log`, `--model` есть.
- `core/agent.py` — `TextActionAnalyzer` (детерминированный анализатор фраз) как образец.

## Границы этапа

- **Субагент = дочерний процесс** `Kod.py`, **не** новая подсистема диалога.
- **Субагент ≠ переход:** запуск **не** меняет `TaskStage` и не пишет в `transition_log`.
- **Не** добавляем pip-зависимостей; `shell=False`; аргументы — списком.
- Запись — только в `users/sub_*/` и `stages/`.

## Шаги

### ШАГ 4.1 — `core/subagents.py` (агент)

- `SubagentRunner.run(task_text, service="lmstudio", model=None, timeout=…, max_turns=…)`.
- Реализация — **дочерний процесс**:
  `.venv/bin/python Kod.py --user sub_<slug> --model <local-id> --oneshot "<задача>" --log dev/logs_reports/stages/subagent_<slug>.md`.
- Никакого нового агентного цикла: весь REPL/память/гейты переиспользуются.

### ШАГ 4.2 — Флаг `--oneshot` (`Kod.py`)

Новый минимальный флаг: один обмен → печать ответа → выход (используется субагентами и фасадом).

### ШАГ 4.3 — Триггеры

- Явная команда: `/subagent run <задача> [--service ollama|lmstudio] [--model <id>] [--wait|--async]`.
- Естественная фраза «**сделай локально в ollama/lm studio** …» распознаётся детерминированным
  анализатором (тот же принцип, что `TextActionAnalyzer`) и порождает **подтверждение** перед запуском.

### ШАГ 4.4 — Отображение и безопасность

- В основной сессии: `[Субагент] id=…, сервис=…, модель=…, pid=…`, затем итог и путь к логу;
  в логе субагента — его собственная подпись модели (требование «во всех CLI-сессиях» выполнено).
- Ограничения: жёсткий `timeout` (по умолчанию 120 с) и `kill` по истечении; лимит
  одновременных субагентов (2); запрет облачного флага, если запрошен локальный сервис;
  рабочий каталог проекта; `shell=False`.

### ШАГ 4.5 — Тесты `test_subagents.py`

Запуск → непустой результат → лог создан с подписью модели; таймаут → статус `timed_out`,
процесс убит; неизвестный сервис → отказ до запуска; облачный сервис при `--local-only` →
отказ; `TaskStage` и память основной задачи не изменены. **Живой прогон — на локальной модели.**
