### ШАГ 7.3 — Проверить, что все якоря резолвятся

```bash
# Извлечь якоря из оглавления и проверить наличие заголовка, который их порождает
python3 - <<'PY'
import re, unicodedata
src = open('README.md', encoding='utf-8').read()
toc = src.split('## Содержание')[1].split('---')[0]
anchors = re.findall(r'\]\(#([^)]+)\)', toc)
def slug(h):
    s = h.strip().lower()
    s = re.sub(r'[`*_]?', '', s)
    s = re.sub(r'[^0-9a-zа-яё\s-]', '', s)
    return re.sub(r'\s+', '-', s.strip())
heads = [slug(m.group(1)) for m in re.finditer(r'^##\s+(?!Содержание)(.+)$', src, re.M)]
bad = [a for a in anchors if a not in heads]
print('пунктов оглавления:', len(anchors))
print('заголовков ##:', len(heads))
print('неразрешённых якорей:', bad if bad else 'нет')
PY
```

**Ожидаемо:** `неразрешённых якорей: нет`. Если остались — поправить якорь (не заголовок).
