## 5. Шаги

### 11.1. Полный регрессионный прогон — Исполнитель

Действие: прогнать базовый набор этапа 0 и все новые тесты; сравнить числа с
базовой линией.
Ожидаемый результат: `$LOGS/s11_regression.txt`: было → стало по каждому набору.
Проверка: расхождения объяснены; рост падений — блокер.

### 11.2. E2E «калькулятор формул» — Исполнитель + Оператор

Действие: на чистом проекте пройти путь: идея → интервью → требования →
архитектура → план → реализация → тесты → review → diff → PR-симуляция →
delivery в `exports/`.
Ожидаемый результат: `$ART/e2e_r9/`: артефакты стадий, diff, Test Report,
ReviewFinding, `exports/`, лог сессии.
Проверка: повтор с нуля даёт тот же результат; ни один шаг не пишет напрямую.
Ветвление: падение на стадии → карточка, этап остаётся открытым; исправление — в
соответствующем этапе, не «заплаткой» в финале.

### 11.3. Приёмочный гейт — Исполнитель

Действие: расширить гейт: DoD §11.3 мастер-плана, security scan, отсутствие
секретов, доступность путей, согласованность чисел.
Ожидаемый результат: таблица «проверка → доказательство → да/нет».
Проверка: каждая строка имеет артефакт или запись.

### 11.4. Синхронизация документации — Исполнитель

Действие: привести `docs/` к факту: реализовано/экспериментально/задел; обновить
Wiki и README; прогнать `check_docs_links.py`.
Ожидаемый результат: 0 битых ссылок; описание соответствует коду.
Проверка: выборочная сверка 5 утверждений с кодом.

### 11.5. Архив и очистка — Оператор

Действие: скопировать утверждённые мастер-план, журнал, рабочие планы в
`dev/old_vers/9/`; зафиксировать sha256; удалить временное из `$WORK/tmp` (кроме
доказательств).
Ожидаемый результат: архив полон; отпечатки в журнале.
Проверка: файлы читаются; хэши совпадают.

### 11.6. Ретро, статус, handoff — Исполнитель

Действие: заполнить «Итог проекта», «Статус для заказчика», ретроспективу: находки,
что сработало, что нет; предложить коммит `chore(r9): finalize revision 9`.
Ожидаемый результат: журнал закрыт; передача описана.
Фиксация: приёмка Ф-30 (кто, что, на каком доказательстве, когда).
