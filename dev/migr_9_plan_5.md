## 5. Шаги

### 5.1. Инвентаризация shell/git — Исполнитель

Действие: найти все `subprocess`, `os.system`, `shell=True`, вызовы git.
Ожидаемый результат: `$LOGS/s5_shell_git_inventory.txt`.
Проверка: каждая точка имеет путь и владельца.

### 5.2. Безопасный shell — Исполнитель

Действие: `ALLOWED_COMMANDS` (имя → аргументы/валидатор); запуск массивом без
`shell=True`; `cwd` — корень проекта; timeout; лимиты CPU/памяти; allowlist
переменных окружения; отдельный пользователь ОС или sandbox-контейнер; запрет
метасимволов и подстановок; вывод — с маскированием.
Ожидаемый результат: команда вне allowlist и инъекция не исполняются.
Проверка: `;`, `&&`, `$(...)`, backticks, проброс env, превышение timeout.

### 5.3. Git-адаптер — Исполнитель

Действие: `git_status`, `git_diff`, `git_log` — чтение; каркас `create_branch`/
`commit` без включения; жёсткий запрет `push`, `reset --hard`, `clean -fd`,
`checkout -- .`, `filter-branch`; все вызовы через allowlist и sandbox.
Ожидаемый результат: чтение работает; запрещённые команды отклоняются до запуска.
Проверка: таблица «команда → ожидаемо».

### 5.4. Тесты, регрессия, журнал — Исполнитель

Действие: security-набор shell/git; базовый набор; журнал; перечитывание; коммит
`feat(shell): add allowlisted shell and read-only git adapter`.
