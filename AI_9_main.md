**Ключчевые правила проекта AI Advent AI_9**

- включи скил text-mode-translator
- все проекты и подпроекты в /AI_9/ выполняются в рамках Python-стека
- в корне проекта находятся: 
. подпроекты Nedela_N (разбиты по неделям Nedela_1, Nedela_2, Nedela_N и так дале, по мере роста проекта)
. Step-3.5-Flash_params.md - данные об основной LLM 
. .env - API_KEY для доступа к основной LLM
. .env.example - образец API_KEY 
. .gitignore - исключения для GitHub

- неделяи (Nedela_....) разбиты по дням (den_01, den_02, и так дале, по мере роста проекта (нумерация сквозная для всех недель))

- каждая Nedela_ содержит обязательные файлы:
-- README_N...md - подробное описание подпроектов недели
-- копия .env, .env.example, .gitignore, Step-3.5-Flash_params.md


- каждый день (den_...) содержит обязательные файлы:
-- README_d...md - описание подпроектов дня
-- Den_..._Kod.py - код подпроекта
-- run_den....sh - запускающий скрипт
-- run_den....desktop - запускающий ярлык
