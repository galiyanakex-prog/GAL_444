# main-tk.py — Графический интерфейс для запуска Den_*.py

Весь проект находится в корне `/AI_9/`. Программы `Den_1_Kod.py`, `Den_2_Kod.py`, `Den_3_Kod.py`, `Den_4_Kod.py`, `Den_5_Kod.py` запускаются через `main-tk.py`.

## Архитектура

`main-tk.py` — окно чата с:
- Выпадающим списком выбора программы (Den_1…Den_5)
- Панелью опций выбранной программы (флаги, числовые поля)
- Областью чата с историей запросов/ответов
- Программы запускаются как подпроцессы (`subprocess`) с передачей ввода/вывода через pipe.

## Функционал

- Запуск выбранной программы
- Отправка сообщений через окно чата
- Хранение истории запросов в файле `chat-log.md`
- Сохранение файла после каждого нового сообщения и при закрытии `main-tk.py`
- При повторном запуске чата старая история очищается

## Формат chat-log.md

```markdown
[2026-09-05]

Den_2_Kod.py | 12:30
Вы: Приготовь борщ

Бот: [ответ]

Den_2_Kod.py | 12:31
Вы: А суп?

Бот: [ответ]
```

## Опции программ

У каждой программы свои опции. Показываются только релевантные для выбранной программы.

### Den_1_Kod.py — Простой чат
Флагов нет.

### Den_2_Kod.py — Сравнение режимов контроля ответа
| Опция | Тип | Описание |
|---|---|---|
| `--free` | чекбокс | Свободный режим — без ограничений |
| `--json` | чекбокс | JSON-режим — строгий формат ответа с валидацией |
| `--stop-sequence` | текст | Стоп-последовательность (модель остановится при её обнаружении) |
| `--temperature` | число (0.0–2.0) | Температура генерации (по умолчанию: 0.7) |
| `--max-tokens` | число | Максимальное количество токенов в ответе (по умолчанию: 500) |

### Den_3_Kod.py — Сравнение способов рассуждения
| Опция | Тип | Описание |
|---|---|---|
| `--direct` | чекбокс | Прямой ответ — без дополнительных инструкций |
| `--step-by-step` | чекбокс | Пошаговое решение (chain-of-thought) |
| `--generate-prompt` | чекбокс | Сначала модель составляет промпт, затем решает задачу |
| `--experts` | чекбокс | Группа экспертов — аналитик, инженер, критик |
| `--compare` | чекбокс | Запустить финальное сравнение всех способов |
| `--expected-answer` | текст | Эталонный ответ для сверки (необязательно) |
| `--temperature` | число (0.0–2.0) | Температура генерации (по умолчанию: 0.7) |
| `--max-tokens` | число | Максимальное количество токенов в ответе (по умолчанию: 500) |

### Den_4_Kod.py — Сравнение температур генерации
| Опция | Тип | Описание |
|---|---|---|
| `--temp-0.3` | чекбокс | Температура 0.3 — детерминированный ответ |
| `--temp-0.7` | чекбокс | Температура 0.7 — баланс точности и разнообразия |
| `--temp-1.3` | чекбокс | Температура 1.3 — высокая креативность |
| `--compare` | чекбокс | Запустить финальное сравнение всех способов |
| `--temperature` | число (0.0–2.0) | Произвольная температура (по умолчанию: нет) |
| `--max-tokens` | число | Максимальное количество токенов в ответе (по умолчанию: 500) |

### Den_5_Kod.py — Сравнение моделей LLM
| Опция | Тип | Описание |
|---|---|---|
| `--weak` | чекбокс | Слабая модель — Llama 3 8B Lunaris |
| `--medium` | чекбокс | Средняя модель — GPT-5 Nano |
| `--strong` | чекбокс | Сильная модель — DeepSeek V4 Pro |
| `--compare` | чекбокс | Запустить финальное сравнение всех моделей |
| `--model` | текст | Произвольная модель (идентификатор из каталога routerai.ru) |
| `--temperature` | число (0.0–2.0) | Температура генерации (по умолчанию: 0.7) |
| `--max-tokens` | число | Максимальное количество токенов в ответе (по умолчанию: 500) |

## Примечания

- Флаги-чекбоксы можно произвольно включать/выключать.
- Числовые поля (`--temperature`, `--max-tokens`) показываются всегда, но применяются только если введены.
- Текстовые поля (`--stop-sequence`, `--expected-answer`, `--model`) показываются только для соответствующих программ.
