# Checks

## Перед ходом
- L1 выполнен: русское запрос-сообщение превращено в machine English.
- Все рассуждения, заметки, tool-calls — machine English, без русских слов.
- Пользовательские строки помечены `USER:`; остальное остаётся внутренним.
- За ход — не больше одного вызова на IN и одного на OUT.

## Перед запуском скрипта
- Режим определён (явный `mode=...` или по формулировке).
- Многострочный/длинный текст передаётся через `--file` или stdin, не `--text`.
- `--model` — только `koda-pro` или `koda-base`.

## Коды выхода
- `0` — конвейер выполнен, блоки напечатаны.
- `1` — шаг не выполнен (ошибка API, неверный формат ответа).
- `2` — ошибка конфигурации: нет токена koda-auth или пустой вход.
- `3` — gate не нашёл пользовательских строк: молчаливый ход, 0 запросов.

## После запуска скрипта
- Нужный блок на месте: `[IN]` для in/roundtrip/ask, `[OUT]` для
  out/gate/batch/roundtrip/ask.
- Значения токена в выводе нет.
- Смысл сохранён: новых фактов нет, ограничения не потеряны.
- Структура сохранена: списки остались списками, идентификаторы и числа не изменены.
- Русский читается естественно, не калькой; код и пути не переведены.
- Длина адекватна: сжатая форма не длиннее исходника, русский вывод не раздут.

## Проверка автоматического пайплайна
- Русское сообщение пользователя прошло через L1 IN до обработки.
- Рассуждения остались на machine English.
- До шага перевода дошли только `USER:`-строки.
- Пользователь увидел только `[OUT]`.
- Сырого EN-ответа и рукописного русского в обход конвейера нет.
- Молчаливые ходы не дали ни вывода, ни запроса.

## Обработка сбоев
- Exit 2 «Токен koda-auth не найден»: проверить
  `~/.config/koda/credentials.json` (`kodaAuth.accessToken`) или передать
  `--token-file`. Токен в чат не вставлять.
- Exit 1 с 429: повторы исчерпаны — подождать, затем перезапустить.
- Exit 1 с сетевой ошибкой: проверить доступность api.kodacode.ru и токен.
- Повторные сбои перевода: сообщить один раз (как `USER:`-строка), дальше
  работать на английском и один раз это отметить.
- Ручной перевод вместо неудачного вызова запрещён.

## Проверка без расхода квоты
`--dry-run` собирает конвейер и печатает обрезанные заглушки вместо запросов.
Использовать для проверки путей и аргументов перед реальным прогоном.
