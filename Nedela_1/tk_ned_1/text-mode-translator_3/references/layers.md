# Layers

Три слоя. Русский — только на входе и на выходе, причём на выходе лишь то, что
требует реакции пользователя.

## L1 IN (`mode=in`, alias `compress`)
Input: русское сообщение пользователя, без правок.
Envelope: «перевести русский текст на machine English».
Pipeline: RU -> EN machine (1 API call, 0 при попадании в таблицу коротких
ответов или в кэш).
Return to agent: `[IN]` — единственный текст, с которым агент дальше работает.

## L2 CORE (без скрипта)
Machine English only: рассуждения, план, tool-call аргументы, логи, заметки,
`.mem`, черновики коммитов, промежуточные проверки.
0 API calls. Никакого русского. Никакого обратного перевода.

## Gate (решение агента, не API)
В L3 OUT попадает только текст, требующий реакции/осведомления пользователя:
вопрос, просьба подтвердить, итог задачи, блокирующая ошибка, риск, действие
которое должен выполнить пользователь.
Всё остальное остаётся в EN и не показывается.

## L3 OUT (`mode=out`, alias `restore`)
Input: EN machine текст, прошедший gate.
Envelope: «перевести machine English на понятный русский».
Pipeline: EN machine -> RU (1 API call, 0 при попадании в кэш).
Return to user: только `[OUT]`.

## L3 OUT batch (`mode=batch`)
Input: несколько EN machine строк (по одной на строку файла/stdin).
Pipeline: все не-кэшированные строки — ОДНИМ API вызовом.
Return to user: один `[OUT]` блок с сохранением нумерации.
Это предпочтительный способ, когда пользовательских строк больше одной.

## roundtrip (`mode=roundtrip`)
RU -> EN machine -> RU (2 API calls). Служебная проверка точности слоёв IN+OUT.
Return: `[OUT]`; `[IN]` по запросу.

## ask (`mode=ask`)
RU -> EN machine -> ответ модели на EN machine -> RU (3 API calls).
Ответ даёт модель Koda, не агент. Return: `[OUT]`; `[ANSWER-EN]` по запросу.

## Auto-selection
- русское сообщение, явного режима нет -> полный ход: L1 IN -> L2 CORE -> gate -> L3 OUT
- `mode=...` всегда выигрывает -> standalone-режим скрипта
- «сожми / в машинный стиль» -> `in`
- «разверни / обратно на русский» (вход — телеграфный EN) -> `out`
- «несколько реплик одним переводом» / несколько пользовательских строк за ход -> `batch`
- «покажи обе формы / проверь потерь» -> `roundtrip`
- «реши через эндпоинт Koda» -> `ask`
- непонятно -> один короткий вопрос (он сам проходит gate и L3 OUT)

## Cost note
Бюджет хода: 1 вызов на IN (0 при кэше/таблице) + максимум 1 вызов на OUT.
Повторяющиеся формулировки и односложные ответы бесплатны.
Меньший режим предпочтительнее: `in`/`out` < `roundtrip` < `ask`; серии `out`
заменять на один `batch`.
