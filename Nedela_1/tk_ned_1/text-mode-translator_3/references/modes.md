# Modes

Режимы скрипта `scripts/tmt.py`. Метки вывода: `[IN]`, `[ANSWER-EN]`, `[OUT]`.

## Автоматический ход агента (default для русского входа)
1. L1 IN: `--mode in --text "<RU как есть>"` -> агент работает только с `[IN]`.
2. L2 CORE: рассуждения, план, tool-calls — machine English, без скрипта.
3. Gate: решение агента — какие строки требуют реакции пользователя.
4. L3 OUT: `--mode out` (одна строка) или `--mode batch` (несколько строк,
   один запрос) -> пользователю показывается только `[OUT]`.

## gate (вспомогательный режим скрипта)
Input: весь internal-блок хода (можно с обёрткой ```internal).
Скрипт оставляет только строки `USER:` (префикс снимает) и переводит их.
Строк `USER:` нет -> exit 3, 0 запросов, молчаливый ход.
Удобно, когда агент помечает пользовательские строки прямо в заметках хода.

## in (алиас compress)
RU -> EN machine (1 API call; 0 при кэше/таблице коротких ответов).
Return: `[IN]`.

## out (алиас restore)
EN machine -> RU (1 API call; 0 при кэше).
Return: `[OUT]`.

## batch
Несколько EN machine строк (одна на строку входа) -> RU одним запросом.
Нумерация сохраняется; при сбое парсинга строка возвращается как есть.
Return: `[OUT]`.

## roundtrip
RU -> EN machine -> RU (2 API calls). Проверка потерь на слоях.
Return: `[OUT]`; `[IN]` по запросу.

## ask
RU -> EN machine -> ответ модели на EN machine -> RU (3 API calls).
Ответ даёт модель Koda, не агент.
Return: `[OUT]`; `[ANSWER-EN]` по запросу.

## Auto-selection
- русское сообщение, явного режима нет -> полный ход (in -> core -> gate -> out)
- `mode=...` всегда выигрывает -> standalone-режим скрипта
- «сожми / в машинный стиль» -> `in`
- «разверни на русский» (вход — телеграфный EN) -> `out`
- «несколько реплик одним переводом» -> `batch`
- «покажи обе формы / проверь потери» -> `roundtrip`
- «реши через эндпоинт Koda» -> `ask`
- непонятно -> один короткий вопрос (он сам проходит gate и L3 OUT)

## Cost note
Бюджет хода: 1 вызов на IN (0 при кэше/таблице) + максимум 1 вызов на OUT.
Молчаливый ход = 0 вызовов. Меньший режим предпочтительнее:
`in`/`out` < `roundtrip` < `ask`; серию `out` заменять одним `batch`.
