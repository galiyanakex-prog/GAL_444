# TMT — Translation Middleware Tool v3

Слоёный переводчик для агентного CLI. Русский остаётся только на двух
границах, всё промежуточное — на machine English.

```
RU input → [L1 IN] → machine English → агент думает и работает на английском
                                         ↓
                       [gate] → нет USER:-строк  → exit 3, молчать, 0 запросов
                       [gate] → есть USER:-строки → [L3 OUT/batch] → RU → user
```

## Требования

- Python 3 + пакет `requests` (в проекте — из `.venv`).
- Токен koda-auth: переменная окружения `KODA_AUTH_TOKEN`, либо
  `~/.config/koda/credentials.json` (поле `kodaAuth.accessToken`), либо файл
  из `--token-file` (первая строка). Токен читается лениво — только когда
  реально нужен запрос к API.

## Быстрый старт

```bash
# входящий текст от пользователя → машинный английский
python3 scripts/tmt.py --mode in --text "Нужен файл конфигурации в формате JSON"
# → [IN] Need configuration file in JSON format.

# агент хочет что-то показать пользователю → русский
python3 scripts/tmt.py --mode out --text "Config is set. Restart service now?"
# → [OUT] Конфигурация задана. Перезапустить службу сейчас?
```

## Режимы

| Режим | Направление | API-вызовов | Назначение |
|---|---|---|---|
| `in` (алиас `compress`) | RU → EN machine | 1 (0 при кэше/таблице) | Перевод входа в машинный английский |
| `out` (алиас `restore`) | EN machine → RU | 1 (0 при кэше) | Перевод того, что увидит пользователь |
| `gate` | блок → `USER:`-строки → RU | 0 или 1 | Главный режим L3: фильтр + перевод |
| `batch` | неск. EN строк → RU | 1 на все строки | Серия реплик одним вызовом |
| `roundtrip` (default) | RU → EN → RU | 2 | Контроль потерь на обоих слоях |
| `ask` | RU → EN → ответ EN → RU | 3 | Ответ даёт модель Koda, не агент |

Модель по умолчанию — `koda-pro` для всех режимов; `--model koda-base` —
альтернатива. Другие модели запрещены.

### Gate — главная экономия

`gate` принимает блок машинного английского и оставляет только строки с
префиксом `USER:` (префикс снимается, порядок сохраняется). Всё без `USER:`
считается внутренними заметками и не показывается. Обёртку ```` ```internal ````
скрипт снимает автоматически.

```bash
printf 'reading config\n3 files scanned\nUSER: Overwrite existing file?\n' \
  | python3 scripts/tmt.py --mode gate
```

```
[OUT]
Перезаписать существующий файл?
```

Если `USER:`-строк нет — stdout пустой, в stderr «молчаливый ход», **exit 3**,
0 запросов. Отдельного промпта у gate нет: фильтрация детерминирована в коде,
переводится уже отфильтрованный текст промптом `out`.

### Batch

Один вызов API на несколько строк, нумерация сохраняется построчно.
Нераспознанная моделью строка остаётся на английском (честный EN лучше тихой
подстановки). Одна строка в batch уходит как обычный `out`.

### Roundtrip и Ask

`roundtrip` печатает и `[IN]`, и `[OUT]` для контроля качества. `ask`
добавляет шаг `answer` (модель отвечает на машинном английском) и печатает
`[ANSWER-EN]` перед `[OUT]`.

## Опции

```
--mode {in,out,gate,batch,roundtrip,ask,compress,restore}   (default: roundtrip)
--text TEXT        текст (иначе stdin)
--file FILE        прочитать текст из файла (UTF-8)
--model {koda-pro,koda-base}   (default: koda-pro)
--temperature FLOAT            (default: 0.2)
--max-tokens INT               (default: 900; 0 = не передавать)
--token-file PATH              файл с токеном (первая строка)
--cache PATH                   файл кэша (default: <скилл>/.cache/tmt_cache.json)
--no-cache                     не читать и не писать кэш
--raw                          только текст без меток [OUT]
--json                         машиночитаемый вывод
--dry-run                        собрать конвейер без запросов к API
```

Код, пути, команды и идентификаторы промпты просят оставлять без перевода.

## Коды выхода

| Код | Значение | Что делает агент |
|---|---|---|
| 0 | успех | использовать вывод |
| 1 | ошибка API / сети / разбора ответа | показать stderr, остановиться |
| 2 | нет токена, пустой ввод, неверные аргументы | показать stderr, остановиться |
| 3 | gate не нашёл `USER:`-строк | молчать, работать дальше (0 запросов) |

## Контракт с агентом

1. **Внутренний язык агента — machine English.** Всё, что пользователь не
   видит (рассуждения, план, аргументы инструментов, логи, заметки, черновики
   коммитов) — на английском.
2. **Пользовательский вывод — только через `out`, `batch` или `gate`.** Русскую
   фразу нельзя печатать руками: она проходит L3 OUT.
3. **Исключения из перевода.** Код, пути, команды, идентификаторы, числа,
   единицы — остаются в исходном виде.
4. **Ошибки не переводятся.** При exit 1 или 2 агент показывает строку ошибки
   как есть и останавливается. Ручного перевода-заглушки нет.
5. **Токен не выводится.** Ни в stdout, ни в логи, ни в коммит.

## Промпты

Системные промпты зашиты в `scripts/tmt.py` в словаре `PROMPTS`
(`in`, `out`, `batch`, `answer`) — правятся в коде. Для `gate` промпта нет,
фильтрация `USER:` сделана регуляркой.

## Экономия запросов

- `gate` на молчаливом ходе — 0 запросов (exit 3);
- односложные ответы (`да`, `нет`, `продолжай`, `отмена`, `спасибо`, …)
  разрешаются словарём `SHORT_ANSWERS` в `in` — 0 запросов;
- повтор текста того же режима/модели берётся из кэша — 0 запросов.

## Кэш

Файл `<скилл>/.cache/tmt_cache.json`, ключ — `sha256(шаг|модель|текст)`.
Ограничен последними 500 записями. Неудачные ответы в кэш не пишутся.
Отключение: `--no-cache`; своё место: `--cache <путь>`.

## Тестирование

```bash
# без сети и без токена
python3 scripts/tmt.py --mode in --dry-run --text "тест"

# с реальным API
python3 scripts/tmt.py --mode roundtrip --text "Нужен файл конфигурации в формате JSON."

# gate: скрыть шум, показать вопрос
printf 'done\nUSER: Proceed?\n' | python3 scripts/tmt.py --mode gate

# молчаливый ход → exit 3
python3 scripts/tmt.py --mode gate --text "only internal notes"; echo $?
```
