# День 2 — формат ответа

Второе практическое задание курса AI Advent по контролю формата ответа языковой модели через API.

## Задание

Отправить один и тот же запрос к LLM в разных режимах контроля ответа и сравнить результаты:

- отправить запрос **без ограничений** — свободная форма ответа;
- отправить запрос **с ограничениями** — детерминированный формат ответа.

Необходимо реализовать:

- явное описание формата ответа (JSON, Markdown, YAML);
- ограничение на длину ответа;
- условие завершения ответа (`stop sequence` или явная инструкция в промпте).

## Результат

Скрипт на Python с CLI-флагами и интерактивным режимом, который отправляет один и тот же запрос к модели `stepfun/step-3.5-flash` через `routerai.ru` API в разных режимах контроля и выводит сравнение результатов.

## Что реализовано

- загрузка API-ключа из переменной окружения через `dotenv`;
- подключение к `routerai.ru` API через `requests`;
- **интерактивный режим** — без флагов запускается цикл ввода;
- переключение режимов ответа через флаги CLI (`--free`, `--json`, `--stop-sequence`);
- отправка одного и того же запроса в разных режимах;
- вывод ответов для сравнения;
- обработка ошибок API (HTTP, сетевые, неверный формат ответа);
- валидация JSON-ответа по структуре;
- извлечение JSON из markdown-обёртки (` ```json ... ``` `);
- настройка температуры генерации (`--temperature`);
- настройка лимита токенов (`--max-tokens`).

## Как работает программа

### Режимы работы

Программа поддерживает два режима работы:

**Интерактивный режим** — запускается без флагов, ожидает ввод пользователя:

```bash
python den_02/Den_2_Kod.py
```

**Однократный запуск** — с флагами CLI для конкретного запроса:

```bash
python den_02/Den_2_Kod.py --free "Напиши рецепт салата Цезарь"
```

### Режимы ответа

Программа поддерживает три режима, переключаемые через флаги CLI:

**Свободный режим** (`--free`) — модель отвечает в произвольной форме, без ограничений.

```bash
python den_02/Den_2_Kod.py --free "Напиши рецепт салата Цезарь"
```

**JSON-режим** (`--json`) — модель возвращает ответ в строгом JSON-формате с фиксированной структурой. В системный промпт добавляется смысловое ограничение (не более 100 слов). Ответ автоматически очищается от markdown-обёртки (` ```json ... ``` `) и проходит валидацию.

```bash
python den_02/Den_2_Kod.py --json "Напиши рецепт блюда"
```

**Режим с stop sequence** (`--stop-sequence`) — модель останавливает ответ при достижении заданной стоп-последовательности.

```bash
python den_02/Den_2_Kod.py --stop-sequence "Конец ответа." "Опиши процесс приготовления"
```

**Запустить все режимы** (`--all`):

```bash
python den_02/Den_2_Kod.py --all "Напиши рецепт салата Цезарь"
```

### JSON-формат ответа

В JSON-режиме модель должна возвращать ответ с фиксированной структурой. Значения могут отличаться (это нейросеть), но формат — одинаковый.

Пример для рецепта:

```json
{
  "ingredients": [
    {"name": "куриная грудка", "weight": "300", "order": 1},
    {"name": "салат ромэн", "weight": "100", "order": 2},
    {"name": "соус Цезарь", "weight": "50", "order": 3}
  ],
  "steps": [
    "Отварить курицу",
    "Нарезать салат",
    "Смешать ингредиенты"
  ]
}
```

### Извлечение JSON из markdown-обёртки

Модель часто возвращает JSON в markdown-обёртке:

```
```json
{ ... }
```
```

Функция `extract_json()` автоматически убирает обёртку и извлекает чистый JSON перед валидацией.

### Системный промпт

Первым элементом истории создаётся сообщение с ролью `system`:

```python
messages = [
    {
        "role": "system",
        "content": "Ты полезный ассистент. Отвечай на русском языке.",
    }
]
```

В JSON-режиме в системный промпт добавляется инструкция о формате ответа и смысловое ограничение длины:

```python
{
    "role": "system",
    "content": (
        "Ты полезный ассистент. Отвечай на русском языке. "
        "Формат ответа: JSON с полями ingredients (массив) и steps (массив). "
        "Используй не более 100 слов в ответе."
    ),
}
```

### Stop sequence

Stop sequence задаётся в параметрах запроса к API. Когда модель генерирует текст и встречает стоп-последовательность, генерация останавливается:

```python
data = {
    "model": "stepfun/step-3.5-flash",
    "messages": messages,
    "stop": ["Конец ответа."],
}
```

### Ограничение длины ответа

Двойное ограничение:

1. **Смысловое** — инструкция в системном промпте JSON-режима: «Используй не более 100 слов».
2. **Техническое** — параметр `max_tokens` в запросе (по умолчанию 500 для свободного режима, 2000 для JSON-режима):

```python
data = {
    "model": "stepfun/step-3.5-flash",
    "messages": messages,
    "max_tokens": 500,
}
```

### Температура генерации

Параметр `temperature` контролирует вариативность ответа (0.0–2.0, по умолчанию 0.7). Задается через флаг `--temperature`:

```bash
python den_02/Den_2_Kod.py --free --temperature 0.3 "Напиши рецепт салата Цезарь"
```

### Обработка ошибок

Если переменная `API_KEY` отсутствует, программа завершается с понятным сообщением.

Ошибки API перехватываются в блоке `try/except`:

- `requests.exceptions.HTTPError` — ошибки HTTP (неверный ключ, недоступность сервиса);
- `requests.exceptions.RequestException` — сетевые ошибки (нет соединения, таймаут);
- `KeyError`, `IndexError`, `ValueError` — ошибки разбора ответа (неожиданный формат JSON).

При валидации JSON-ответа используется проверка структуры. Если модель вернула ответ не в том формате, выводится предупреждение.

## Подготовка к запуску

Добавьте `API_KEY` в корневой файл `.env`:

```env
API_KEY=ваш_ключ_от_routerai
```

## Запуск

Из корня репозитория выполните:

```bash
# Интерактивный режим
python den_02/Den_2_Kod.py

# Однократный запуск — свободный режим
python den_02/Den_2_Kod.py --free "Напиши рецепт салата Цезарь"

# Однократный запуск — JSON-режим
python den_02/Den_2_Kod.py --json "Напиши рецепт блюда"

# Однократный запуск — stop sequence
python den_02/Den_2_Kod.py --stop-sequence "Конец ответа." "Опиши процесс"

# Запустить все режимы для сравнения
python den_02/Den_2_Kod.py --all "Напиши рецепт салата Цезарь"

# С настройкой температуры и лимита токенов
python den_02/Den_2_Kod.py --all --temperature 0.3 --max-tokens 300 "Напиши рецепт"
```
