# AI Advent — практика работы с LLM API

Учебный репозиторий с практическими заданиями курса AI Advent.

Проект последовательно знакомит с работой через LLM API: от первого запроса и сохранения истории диалога до управления форматом ответа, температуры генерации, способов рассуждения и сравнения разных моделей.

## Выполненные задания

| День | Тема | Результат |
|---|---|---|
| [День 1](001_День%201) | Первый запрос к LLM через API | Консольный чат-бот с историей диалога |
| [День 2](002_День%202) | Управление форматом ответа | Сравнение свободного, JSON и stop-sequence режимов |
| [День 3](003_День%203) | Способы рассуждения | Четыре решения одной задачи и их автоматическое сравнение |
| [День 4](004_День%204) | Температура генерации | Исследование влияния temperature на точность, креативность и разнообразие |
| [День 5](005_День%205) | Версии моделей | Сравнение слабой, средней и сильной моделей по качеству, скорости и стоимости |

## Технологии

- Python;
- [routerai.ru API](https://routerai.ru/api/v1/chat/completions);
- модель `stepfun/step-3.5-flash` (основная);
- дополнительные модели: `sao10k/l3-lunaris-8b`, `openai/gpt-5-nano`, `deepseek/deepseek-v4-pro-0813`;
- характеристики, свойства и параметры модели — см. [Step-3.5-Flash_params.md](Step-3.5-Flash_params.md);
- `python-dotenv`.

## Подготовка проекта

### 1. Клонирование

```bash
git clone <url>
cd AI_9
```

### 2. Виртуальное окружение

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

Linux:

```bash
source .venv/bin/activate
```

Windows:

```bash
.venv\Scripts\activate
```

### 3. Зависимости

```bash
pip install -r requirements.txt
```

### 4. API-ключ

Получите ключ в [RouterAI](https://routerai.ru).

Создайте в корне проекта файл `.env` на основе `.env.example`:

```env
API_KEY=ваш_ключ_от_routerai
```

Файл `.env` уже добавлен в `.gitignore`. Не публикуйте его и не передавайте другим людям.

## Запуск заданий

Все команды выполняются из корня репозитория (`AI_9/`).

### День 1 — чат-бот

```bash
# Интерактивный режим
python "001_День 1/Den_1_Kod.py"
```

### День 2 — управление форматом ответа

```bash
# Интерактивный режим
python "002_День 2/Den_2_Kod.py"

# Свободный режим
python "002_День 2/Den_2_Kod.py" --free "Напиши рецепт салата Цезарь"

# JSON-режим
python "002_День 2/Den_2_Kod.py" --json "Напиши рецепт блюда"

# Stop sequence
python "002_День 2/Den_2_Kod.py" --stop-sequence "Конец ответа." "Опиши процесс"

# Все режимы
python "002_День 2/Den_2_Kod.py" --all "Напиши рецепт салата Цезарь"
```

### День 3 — способы рассуждения

```bash
# Интерактивный режим
python "003_День 3/Den_3_Kod.py"

# Прямой ответ
python "003_День 3/Den_3_Kod.py" --direct "Решите задачу: у фермера есть куры и кролики. Всего 15 голов и 42 ноги."

# Пошаговое решение
python "003_День 3/Den_3_Kod.py" --step-by-step "Решите задачу: у фермера есть куры и кролики. Всего 15 голов и 42 ноги."

# Генерация промпта
python "003_День 3/Den_3_Kod.py" --generate-prompt "Решите задачу: у фермера есть куры и кролики. Всего 15 голов и 42 ноги."

# Группа экспертов
python "003_День 3/Den_3_Kod.py" --experts "Решите задачу: у фермера есть куры и кролики. Всего 15 голов и 42 ноги."

# Все способы + сравнение
python "003_День 3/Den_3_Kod.py" --all "Решите задачу: у фермера есть куры и кролики. Всего 15 голов и 42 ноги."

# С эталоном для сверки
python "003_День 3/Den_3_Kod.py" --all "Решите задачу..." --expected-answer "9 кур, 6 кроликов"
```

### День 4 — температура генерации

```bash
# Интерактивный режим
python "004_День 4/Den_4_Kod.py"

# Температура 0.3 — детерминированный
python "004_День 4/Den_4_Kod.py" --temp-0.3 "Как распространяются короткие радиоволны в пространстве?"

# Температура 0.7 — баланс
python "004_День 4/Den_4_Kod.py" --temp-0.7 "Как распространяются короткие радиоволны в пространстве?"

# Температура 1.3 — креативность
python "004_День 4/Den_4_Kod.py" --temp-1.3 "Как распространяются короткие радиоволны в пространстве?"

# Произвольная температура
python "004_День 4/Den_4_Kod.py" --temperature 1.5 "Как распространяются короткие радиоволны в пространстве?"

# Все температуры + сравнение
python "004_День 4/Den_4_Kod.py" --all "Как распространяются короткие радиоволны в пространстве?"
```

### День 5 — версии моделей

```bash
# Интерактивный режим
python "005_День 5/Den_5_Kod.py"

# Слабая модель (Llama 3 8B)
python "005_День 5/Den_5_Kod.py" --weak "У фермера есть куры и кролики. Всего 15 голов и 42 ноги."

# Средняя модель (GPT-5 Nano)
python "005_День 5/Den_5_Kod.py" --medium "У фермера есть куры и кролики. Всего 15 голов и 42 ноги."

# Сильная модель (DeepSeek V4 Pro)
python "005_День 5/Den_5_Kod.py" --strong "У фермера есть куры и кролики. Всего 15 голов и 42 ноги."

# Все модели + сравнение
python "005_День 5/Den_5_Kod.py" --all "У фермера есть куры и кролики. Всего 15 голов и 42 ноги."

# Произвольная модель
python "005_День 5/Den_5_Kod.py" --model "deepseek/deepseek-v4-pro-0813" "У фермера есть куры и кролики. Всего 15 голов и 42 ноги."
```

## Что изучено

### День 1

- создание клиента для работы с LLM API;
- роли `system`, `user` и `assistant`;
- отправка запроса и получение ответа;
- хранение истории текущего диалога;
- обработка ошибок API.

### День 2

- управление структурой ответа через промпт;
- смысловое ограничение длины;
- параметр `max_tokens`;
- явное условие завершения ответа (`stop sequence`);
- сравнение результатов с одинаковым пользовательским запросом;
- валидация JSON-ответа.

### День 3

- прямой запрос без дополнительных инструкций;
- пошаговое решение (chain-of-thought);
- генерация промпта самой моделью;
- имитация группы экспертов;
- автоматическая оценка нескольких решений (LLM-as-a-Judge);
- обработка ограничения токенов в минуту (TPM-лимит);
- опциональная сверка с эталоном.

### День 4

- влияние параметра `temperature` на ответы модели;
- детерминированный ответ (temperature = 0.3);
- баланс точности и разнообразия (temperature = 0.7);
- высокая креативность (temperature = 1.3);
- произвольная температура (0.0–2.0);
- автоматическое сравнение и оценка через LLM-as-a-Judge;
- обработка TPM-лимита с автоматическим retry.

### День 5

- сравнение моделей разного уровня мощности;
- слабая модель (Llama 3 8B Lunaris) — быстрая и дешёвая;
- средняя модель (GPT-5 Nano) — баланс цена/качество;
- сильная модель (DeepSeek V4 Pro) — максимальное качество;
- замер времени ответа, количества токенов и стоимости;
- расчёт стоимости на основе прайса API;
- сводная таблица сравнения метрик;
- LLM-as-a-Judge для оценки соотношения качество/ресурсы.

## Ограничения API

Доступное количество запросов и токенов зависит от тарифного плана. При превышении лимита токенов в минуту (HTTP 429) программы автоматически повторяют запрос после паузы 60 секунд (до 2 попыток).

## Цель репозитория

Главная цель проекта — на небольших запускаемых примерах понять, как формулировка промпта и параметры API влияют на поведение языковой модели.
