> Отметки: ☐ — не выполнено, ✅ — прошло, ❌ — не прошло (записать, что именно).

## Подготовка (3 минуты)

☐ **П.1** Открыть терминал в каталоге `Nedela_2/den_09`.

☐ **П.2** Убедиться, что ключ API на месте:

```bash
grep -q "API_KEY" ../../.env && echo "ключ есть" || echo "ключа НЕТ"
```
Ожидание: «ключ есть».

☐ **П.3** Убедиться, что папка чистая (нет артефактов прошлых прогонов):
```bash
ls
```
Ожидание: НЕТ файлов `den_9_context.json`, `den_9_tokens.csv`, `Den_9_log.md`,
`*.summary.md`. (Появятся в ходе проверки — это нормально.)

## Часть 1. Автосжатие по порогу (5 минут)

☐ **1.1** Запустить в дешёвой конфигурации (порог 3, окно 2 — сжатие видно почти сразу):
```bash
./den_9_run.sh --context compression --memory compressed --window 2 --compress-every 3
```

☐ **1.2** Отправить 6 сообщений по очереди (живой API):
```
Запомни: меня зовут Алексей
Мой любимый цвет — синий
Я живу в Казани
У меня два кота
Работаю программистом
Люблю кофе
```
Ожидание: после накопления 3 сообщений вне окна — `[Сжатие] 3 сообщений свёрнуты в
саммари…`; сжатие повторяется по мере роста (консолидация: старое саммари + новые
сообщения).

☐ **1.3** Ввести `/summary`.
Ожидание: саммари содержит ранние факты (имя, цвет, город) — ничего не потеряно.

☐ **1.4** Ввести `/history`.
Ожидание: пометки `[в саммари]` у старых, `[в окне]` у последних 2; архив хранит
исходные тексты.

☐ **1.5** Спросить: `Как меня зовут и где я живу?`
Ожидание: модель ЗНАЕТ — саммари едет в запрос «под капотом» вместо старой истории.

☐ **1.6** Ввести `/tokens` — убедиться, что служебный запрос сжатия учтён отдельно
(не подменяет «токены текущего запроса»).

☐ **1.7** Ввести `/exit`.

## Часть 2. Ручное сжатие и переключение на лету (4 минуты)

☐ **2.1** Запустить:
```bash
./den_9_run.sh --context compression --memory compressed --window 4
```

☐ **2.2** Отправить 3–4 сообщения, затем ввести `/compress`.
Ожидание: принудительное сжатие всей истории вне окна в саммари.

☐ **2.3** Ввести `/compress off`.
Ожидание: `[Сжатие] выключено` — новые сообщения копятся без сжатия.

☐ **2.4** Отправить ещё 3–4 сообщения (больше порога).
Ожидание: АВТОСжатия НЕТ — режим выключен.

☐ **2.5** Ввести `/compress on`.
Ожидание: `[Сжатие] включено`; при превышении порога сжатие снова срабатывает.

☐ **2.6** Ввести `/exit`.

## Часть 3. Сравнение до/после — /compare (5 минут)

☐ **3.1** Запустить:
```bash
./den_9_run.sh --context compression --memory compressed --window 2 --compress-every 3
```

☐ **3.2** Отправить 5–6 сообщений с фактами (как в Части 1), чтобы саммари накопилось.

☐ **3.3** Ввести `/compare`, на вопрос про живой прогон ответить `N`.
Ожидание: локальная оценка — два варианта запроса («до»: вся история; «после»:
саммари + окно) с числом токенов; «после» заметно короче.

☐ **3.4** Ввести `/compare` снова, ответить `y` (живой прогон).
Ожидание: два РЕАЛЬНЫХ ответа на один контрольный вопрос + экономия токенов/₽
двумя строками. Качество ответа «после» не хуже (факты в саммари).

☐ **3.5** Ввести `/exit`.

## Часть 4. Настройки саммари (3 минуты)

☐ **4.1** Короткое саммари и «сухая» температура:
```bash

```
Отправить 5–6 сообщений, ввести `/summary`.
Ожидание: саммари укладывается в ~30 слов; фактичное, без «творчества».

☐ **4.2** Ввести `/exit`. Проверить файл саммари:
```bash
cat *.summary.md
```
Ожидание: человекочитаемый Markdown с текстом саммари.

☐ **4.3** Перезапуск (4.1).
Ожидание: саммари загружено из файла — сжатое знание пережило перезапуск.
Спросить ранний факт — модель помнит. `/exit`.
