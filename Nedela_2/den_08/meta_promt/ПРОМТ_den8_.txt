- Задание дня: den_08/Задание_Д8.txt — «Работа с токенами»:
  1) добавить в код агента подсчёт токенов: для текущего запроса, для всей истории диалога,
     для ответа модели;
  2) сравнить короткий диалог, длинный диалог и диалог, превышающий лимит модели;
  3) показать, как растут стоимость/токены по мере диалога и что ломается при переполнении.
  Результат: код, который считает токены и показывает, как они влияют на поведение агента.
- Разрешение неоднозначностей задания (сформулировано в чате курса руководителем и
  участниками — считать авторитетным):
  а) «токены текущего запроса» = usage.prompt_tokens: в нейронку каждый раз целиком
     отправляется весь диалог (system + история), модель не хранит состояние — храним мы;
  б) «вся история диалога» = сумма всех prompt_tokens + completion_tokens за сессию
     (последний промпт = N, а за чат потрачено 1+2+…+N);
  в) отдельно показывать ЛОКАЛЬНУЮ оценку токенов последнего сообщения пользователя
     (~chars/4, для кириллицы ~len/3) и помечать её как приблизительную; авторитет — usage;
  г) переполнение лимита моделировать искусственно (--max-context-tokens, max_tokens),
     а не «сжигать» реальные 262K токена — токены это реальные деньги;
  д) «что ломается» показывать кодом: ошибка API при переполнении контекста, вытеснение
     старых сообщений при обрезке окна, урезанный ответ при малом max_tokens.
- Теоретическая база: Nedela_2/Суть_N2.txt — §2.3 «Контекстное окно» (один диалог с кодом
  8–10K токенов, ~100 сообщений → лимит → History Compression), §2.2 «Токенизация и
  обрезка», §2.1 «отсутствие памяти между сессиями», §7.2 «JSON жрёт много токенов».
- Модель и тариф: Nedela_2/Step-3.5-Flash_params.md — контекстное окно 262K токенов,
  входящие 11 ₽ / 1M, исходящие 33 ₽ / 1M, параметр max_tokens поддерживается.
- База кода: den_07/den_7_Kod.py (1667 стр.) — CLI-чат-бот: класс Agent, 3 стратегии
  контекста (--context), 3 типа памяти (--memory), JSON-снимок контекста, Markdown-лог,
  retry при 429. КРИТИЧНО: донор читает из ответа только choices, блок usage выбрасывает —
  именно это добавляет День 8.
- API: RouterAI, OpenAI-совместимый, endpoint https://routerai.ru/api/v1/chat/completions,
  модель stepfun/step-3.5-flash; ключ — переменная API_KEY в .env (load_dotenv()).
- Окружение: общий venv недели Nedela_2/.venv (python 3.13; requests, python-dotenv).
  tiktoken в venv НЕТ и ставить без запроса нельзя → основная оценка токенов эвристическая,
  tiktoken подключается опционально через try/except ImportError.
- Стиль кода: учебный однофайловый скрипт, комментарий почти к каждой строке на русском,
  класс Agent, блоки разделены комментариями «1. Импорты…», «4. Константы…» и т.д.
