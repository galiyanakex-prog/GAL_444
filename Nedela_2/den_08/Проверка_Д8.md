> Отметки: ☐ — не выполнено, ✅ — прошло, ❌ — не прошло (записать, что именно).

## Часть 1. Три счётчика токенов (5 минут)

☐ **1.1** Запустить:
```bash
./den_8_run.sh --context sliding-window --memory session
```

☐ **1.2** Отправить короткое сообщение (живой API):
```
Привет! Расскажи анекдот про программистов
```

☐ **1.3** Ввести `/tokens`.
Ожидание: три счётчика —
- «токены текущего запроса» (prompt_tokens: весь отправленный контекст);
- «ответ модели» (completion_tokens);
- «вся история» (накопительная сумма);
плюс локальная оценка последнего сообщения (символы/3–4).

☐ **1.4** Отправить ещё одно сообщение, снова `/tokens`.
Ожидание: «текущий запрос» ВЫРОС (модель stateless — вся история едет заново),
«вся история» выросла сильнее — рост 1+2+…+N виден в цифрах.

☐ **1.5** Ввести `/cost`.
Ожидание: стоимость последнего обмена, всей сессии и прогноз на 100 обменов —
в рублях (входящие 11 ₽/1M, исходящие 33 ₽/1M).

☐ **1.6** Проверить CSV-журнал:
```bash
cat den_8_tokens.csv
```
Ожидание: строка на каждый обмен — номер, время, режим, окно, три счётчика,
стоимость обмена и накопительная стоимость.

☐ **1.7** Ввести `/exit`, запустить снова (1.1), `/tokens`.
Ожидание: накопительные счётчики восстановлены из снимка (токены пережили перезапуск).
`/exit`.
