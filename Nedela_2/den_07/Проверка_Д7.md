# Сценарий ручной проверки — День 7 «Сохранение контекста (JSON-персистентность агента)»

> Чек-лист для живой проверки проекта `Nedela_2/den_07` руками, без автотестов.
> Время прохождения: ~20 минут. Живые запросы к API — платные (≈1–2 ₽ на весь сценарий).
> Отметки: ☐ — не выполнено, ✅ — прошло, ❌ — не прошло (записать, что именно).

## Подготовка (3 минуты)

☐ **П.1** Открыть терминал в каталоге `Nedela_2/den_07`.

☐ **П.2** Убедиться, что ключ API на месте:
```bash
grep -q "API_KEY" ../../.env && echo "ключ есть" || echo "ключа НЕТ"
```
Ожидание: «ключ есть».

☐ **П.3** Убедиться, что папка чистая (нет артефактов прошлых прогонов):
```bash
ls
```
Ожидание: НЕТ файлов `den_7_context.json`, `Den_7_log.md`, `den_7_error.log`.
(Появятся в ходе проверки — это нормально.)

## Часть 1. Базовый сценарий задания — «агент не выключался» (5 минут)

☐ **1.1** Запустить:
```bash
./den_7_run.sh --context sliding-window --memory session
```

☐ **1.2** Отправить (живой API):
```
Запомни: меня зовут Алексей
```
Ожидание: агент подтверждает.

☐ **1.3** Добавить ещё пару сообщений:
```
Мой любимый цвет — синий
Я живу в Казани
```

☐ **1.4** Ввести `/exit`.
Ожидание: `[Память] Контекст сохранён: den_7_context.json` — снимок записан.

☐ **1.5** Проверить файл снимка:
```bash
python3 -m json.tool den_7_context.json | head -25
```
Ожидание: валидный JSON; внутри `version`, `saved_at`, `context_strategy`,
`full_history` (с `role`/`content`/`timestamp`).

☐ **1.6** Запустить снова (1.1).
Ожидание в шапке: `[Память] Контекст восстановлен: N сообщений…`, где N = число
обменов × 2 (не фиксировать точное число — оно зависит от числа сообщений).

☐ **1.7** Спросить: `Как меня зовут и где я живу?`
Ожидание: модель помнит имя и город — ГЛАВНАЯ проверка дня.

☐ **1.8** Ввести `/exit`.

## Часть 2. Персистентность в других режимах (5 минут)

☐ **2.1** Compression-режим со сжатием:
```bash
./den_7_run.sh --context compression --memory compressed --keep 2 --fresh
```
`--fresh` нужен, чтобы снимок Части 1 не перезаписал флаги запуска. Отправить
5–6 сообщений (часть уйдёт в саммари), ввести `/summary`, затем `/exit`.

☐ **2.2** Запустить снова (2.1, но уже БЕЗ `--fresh`).
Ожидание: восстановлены И сообщения, И саммари (`[Память] … саммари: N символов`).
Спросить про ранний факт — модель помнит. `/exit`.

☐ **2.3** Layered-режим:
```bash
./den_7_run.sh --context leveling --memory layered --keep 2 --fresh
```
Отправить `Запомни: дедлайн — 1 октября`, затем `/exit`. Запустить снова (без `--fresh`).
Ожидание: (а) `[слой]` в `/history` и счётчики `/layers` совпадают с первым запуском;
(б) после перезапуска вопрос `Какой у меня дедлайн?` — модель называет дату (high-слой
вне окна доходит до запроса через приоритетный блок). `/exit`.

## Часть 3. Ручное управление (3 минуты)

☐ **3.1** Запустить с `--fresh` (чистая сессия), отправить пару сообщений:
```bash
./den_7_run.sh --context sliding-window --memory session --fresh
```

☐ **3.2** Ввести `/save`.
Ожидание: `[Память] Контекст сохранён…` — ручное сохранение работает.

☐ **3.3** Ввести `/clear`.
Ожидание: контекст в памяти очищен; файл на диске НЕ тронут (проверить:
`python3 -m json.tool den_7_context.json | head -3` — файл на месте).

☐ **3.4** Спросить что-нибудь — модель не помнит прошлое (контекст пуст).

☐ **3.5** Ввести `/load`.
Ожидание: `[Память] Контекст восстановлен: N сообщений…` — история вернулась.
Спросить `Как меня зовут?` — модель помнит.

☐ **3.6** Ввести `/exit`.

## Часть 4. Устойчивость (4 минуты, без API)

☐ **4.1** Отсутствующий файл контекста:
```bash
./den_7_run.sh --context sliding-window --memory session --context-file /tmp/no_such_file.json
```
Ожидание: понятное сообщение («файл не найден, начинаю с чистого листа»), чат работает.
`/exit`.

☐ **4.2** Повреждённый файл контекста:
```bash
echo "битый json" > /tmp/broken_ctx.json
./den_7_run.sh --context sliding-window --memory session --context-file /tmp/broken_ctx.json
```
Ожидание: предупреждение о повреждении, чат стартует с чистого листа, БЕЗ Traceback.
`/exit`.

☐ **4.3** Ctrl+C во время чата: запустить (1.1), отправить сообщение, нажать Ctrl+C.
Ожидание: контекст СОХРАНЁН перед выходом (проверить `saved_at` в JSON), корректный выход.

☐ **4.4** Ctrl+D (EOF) во время чата.
Ожидание: то же — сохранение и корректный выход.

☐ **4.5** Ввод в «ломаной» кодировке (эмуляция CP1251):
```bash
printf '\xcf\xf0\xe8\xe2\xe5\xf2\n/exit\n' | ./den_7_run.sh --context sliding-window --memory session
```
Ожидание: БЕЗ Traceback.

☐ **4.6** Стрелки: в живом чате нажать ↑ — предыдущая команда подставляется (readline).
