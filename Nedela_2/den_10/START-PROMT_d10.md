# START-PROMT_d10 — стартовый промт проекта `den_10` «Управление контекстом: разные стратегии (без summary)»

## 1. Суть дня
К концу дня агент должен **управлять контекстом тремя разными стратегиями и переключаться
между ними**: (1) Sliding Window — только последние N сообщений, остальное отбрасывается;
(2) Sticky Facts / Key-Value Memory — блок фактов «ключ: значение», обновляемый после
каждого сообщения пользователя, в запрос идёт facts + окно; (3) Branching — checkpoint,
две ветки от одного места, независимое продолжение, переключение между ветками. Все три
стратегии прогоняются на одном сценарии («собираем ТЗ, 10–15 сообщений») и сравниваются
по 4 критериям: качество ответа, стабильность, расход токенов, удобство. Формат — код.

## 4. Главная инструкция
Работай **строго по `agents_memory_10/.plan_10`**, подшаг за подшагом, в порядке нумерации
(Блок 0 → 1 → 2 → 3 → 4 → 5 → 6). Отклонения от плана — только с явного согласия
пользователя. **Батч-режим включён по умолчанию** (раздел 6.5 МЕТА-ПРОМТа): независимые
подшаги объединяются по его правилам; отключение — только по прямой фразе пользователя.

## 5. Правила контекста
При новой сессии, потере контекста или непонятном смысле перечитать по порядку:
`agents_memory_10/.plan_10` → `agents_memory_10/.agents_memory_10` (последние отчёты) →
`agents_memory_10/.mem_10` (последние записи) → `meta_promt/ПРОМТ_den10_.txt`.
Первый невыполненный подшаг определять по `.mem_10`, а не по памяти.

## 6. Правила журналов
- После **каждого** подшага (или батча): запись в `.mem_10` (формат: Файл / Было / Стало /
  Проверка / Статус / Дата; для ознакомления — «Соответствует ли заданию» + «Предложения»)
  и краткий отчёт в `.agents_memory_10` (3–5 строк + номера записей + следующий шаг).
- Журналы дописывать файловым инструментом (replace), не shell-heredoc: `$(...)` в командах
  блокируется политикой CLI.
- Предложенные, но не применённые правки остаются в `.mem_10` со статусом
  `⚠️ требует проверки` и закрываются в Блоке 5.

## 7. Критерии приёмки дня
1. `den_10_Kod.py` компилируется; в дне есть `README_d10.md`, `den_10_run.sh`,
   `den_10_run.desktop` (все непустые, `.sh`/`.desktop` исполняемые).
2. **Sliding Window**: только последние N сообщений, старые ОТБРАСЫВАЮТСЯ (удаление —
   подтверждено Алексеем в чате, Ч1); N настраивается (`--window`).
3. **Sticky Facts**: блок `facts` (ключ: значение — цель, ограничения, предпочтения,
   решения, договорённости); обновляется после КАЖДОГО сообщения пользователя отдельным
   служебным LLM-запросом «по шаблону» (Ч3), только новые/изменённые факты; в запрос
   отправляется facts (system-сообщением) + последние N сообщений «сырыми» (Ч2); токены
   обновления учитываются отдельно (урок Ч8 Дня 9).
4. **Branching**: checkpoint → 2 ветки от одного места → независимое продолжение →
   переключение. Требования пользователя: ветки хранятся в директории `Branches/` в папке
   дня, каждая ветка — отдельный файл; активная ветка ВИДНА в терминале (приглашение
   `Вы [имя]:` и шапка); `/branch list` — просмотр; `/branch switch <имя>` — переключение;
   `/branch new <имя>` — создание ветки от текущего места.
5. **Переключатель стратегий**: `--context sliding-window|compression|leveling|facts|branching`
   (старые режимы Дней 6–9 сохраняются — «минимум 3» не означает выбросить готовое).
6. **Сравнение**: `/compare-strategies` прогоняет сценарий «собираем ТЗ, 10–15 сообщений»
   на каждой из трёх стратегий и печатает сравнение по 4 критериям задания (качество,
   стабильность, расход токенов, удобство); живой API — только после явного «y».
7. Снимок v4: facts, active_branch, список веток; снимки v3 (День 9) грузятся без падения;
   приоритет «явный флаг > снимок» сохраняется; файлы веток устойчивы к битому JSON.
8. Уроки Дней 6–9 перенесены: `errors='replace'` для stdin, `try: import readline`,
   токен-учёт и CSV, retry 429, BASE_DIR.
9. Тесты проходят без живого ключа (`API_KEY=test-key`, заглушка `requests`); тестовые
   файлы — в `/tmp`.
10. В коде и файлах дня нет упоминаний «День 9»/«den_9»/«Den_9» (кроме осмысленных ссылок
    на донор в README/метапромтах — по образцу Дня 9).
