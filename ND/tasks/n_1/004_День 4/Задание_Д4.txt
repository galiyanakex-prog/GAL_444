Суть задания (День 4)

  Цель: Исследовать, как параметр temperature влияет на ответы LLM — на точность, креативность и разнообразие.

  Что сделать

  Определить как влияет на разнообразие ответов модели: чем выше, тем более случайным будет вывод.


  Отправить один и тот же запрос с тремя значениями температуры:


  ┌──────────┬──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │ Темпе... │ Ожидаемое поведение                                                                                                  │
  ├──────────┼──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ 0.3      │ Детерминированный ответ. Модель всегда выбирает токен с максимальной вероятностью. Результат предсказуем и одинак... │
  │ 0.7      │ Баланс между точностью и разнообразием. Стандартное значение по умолчанию.                                           │
  │ 1.3      │ Высокая креативность. Модель чаще выбирает менее вероятные токены, ответ становится более вариативным.               │
  └──────────┴──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘


  Что сравнить

   1. Точность — какой ответ наиболее корректен и логичен
   2. Креативность — насколько оригинальны формулировки и подходы
   3. Разнобразие — насколько различаются ответы между запусками с одинаковой температурой

  Итог:
Сформулировать выводы: как с изменением темппературы меняется тоность, креативность и другие каества ответов.

  ---

  Ключевые моменты из чата

   - Можно использовать LLM для оценки — задачу сравнения и формулирования выводов можно поручить самой модели (LLM-as-a-Judge), как в Дне 3.

   - Температуру можно выкручивать шире — Алексей подтвердил: можно экспериментировать не только с 0,3 0.7, 1.3, но и с любыми другими
     значениями (0.9, 1.5, 2.0).

   - Потолок температуры зависит от модели — у DeepSeek реальный потолок ~1.5–2.0, у Anthropic 0–1.0 (1.2 обрезается до 1.0), у Mistral ~1.5.
     Выше потолка — модель «сходит с ума», ответ разваливается на бессвязный текст.

   - Температура влияет не на каждом шаге одинаково — если токен-лидер имеет вероятность ~100%, температура не меняет результат. Реальный
     эффект виден там, где конкуренция между токенами близкая (49% vs 47%).

   - Режим reasoning (рассуждения) автоматически фиксирует низкую температуру — чтобы не сбивать модель с траектории внутреннего рассуждения.

   - Автоматический подбор температуры — можно реализовать двухступенчатый подход: простая модель определяет тип задачи
     (алгоритмическая/креативная) и подставляет нужный конфиг.

  Формат результата

  Код на Python, который отправляет один запрос с разными температурами, выводит ответы и даёт сравнительный вывод.

Дополнительная информация:

Диапазон temperature: 0 ≤ temperature ≤ 2 (стандартный диапазон OpenAI-совместимого API и OpenRouter).

На практике:
    temperature: 0 — максимально детерминированные ответы;
    0.2–0.5 — точные ответы, код, инструкции;
    0.7–1.0 — универсальный режим;
    1.0–1.5 — больше вариативности;
    выше 1.5 — ответы могут стать менее стабильными.

Температура влияет не на каждом шаге одинаково — если токен-лидер имеет вероятность ~100%, температура не меняет результат. Реальный эффект виден там, где конкуренция между токенами близкая (49% vs 47%).

Режим reasoning (рассуждения) автоматически фиксирует низкую температуру — чтобы не сбивать модель с траектории внутреннего рассуждения.

Автоматический подбор температуры — можно реализовать двухступенчатый подход: простая модель определяет тип задачи (алгоритмическая/креативная) и подставляет нужный конфиг.
