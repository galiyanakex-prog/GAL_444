День 5 — Версии моделей

  Суть задания

  Отправить один и тот же запрос к трём моделям разного уровня мощности:

   - Слабая модель — простая, быстрая, дешёвая (или бесплатная)
   - Средняя модель — баланс возможностей и ресурсов
   - Сильная модель — наиболее мощная (например, gpt-solve / gpt-4-уровня)

  Модели можно взять из каталога HuggingFace (ранжированный список моделей), либо использовать те,
  что уже доступны через API (например, DeepSeek — flash как слабая, pro как сильная).

  Что замерить


  ┌────────────────────┬───────────────────────────────────────────┐
  │ Метрика            │ Описание                                  │
  ├────────────────────┼───────────────────────────────────────────┤
  │ Время ответа       │ Сколько секунд модель генерирует ответ    │
  │ Количество токенов │ Сколько токенов потребил запрос и ответ   │
  │ Стоимость          │ Если модель платная — сколько стоил вызов │
  └────────────────────┴───────────────────────────────────────────┘


  Что сравнить

   - Качество ответов — корректность, полнота, логичность
   - Скорость — время генерации
   - Ресурсоёмкость — потребление токенов, стоимость

  Результат

  Короткий вывод о различиях между моделями + ссылки на выбранные модели.

  Формат: код на Python.

  ---

  Ключевые уточнения из чата

   - «Слабость/сильность» — величина относительная, ориентиры: количество параметров, архитектура
     (Dense vs MoE)
   - Задачи можно брать те же логические, что и на предыдущих днях
   - Ссылки в выводе — на сами выбранные модели
   - Желательно включить хотя бы одну бесплатную модель
   - Алексей рекомендует сильную модель типа gpt-solve
