AI_9  День 3. Задание 3 Разные способы рассуждения
Суть задания (День 3)

  Цель: Взять одну задачу (логическую, алгоритмическую или аналитическую) и решить её через API
  четырьмя разными способами рассуждения, затем сравнить результаты.

  Четыре способа:

   1. Прямой ответ — отправляешь промпт с задачей без каких-либо дополнительных инструкций по
      рассуждению.

   2. Пошаговое решение — в промпт добавляешь инструкцию: «решай пошагово» (chain-of-thought).

   3. Генерация промпта — сначала просишь модель саму составить оптимальный промпт для решения задачи,
       а затем используешь этот сгенерированный промпт для получения ответа.

   4. Группа экспертов — в системном промпте создаёшь роль группы экспертов (например: аналитик,
      инженер, критик) и получаешь решение от каждого эксперта отдельно.

  Что сравнить:
   - Отличаются ли ответы между собой?
   - Какой способ дал наиболее точный и качественный результат?

  Формат результата:
  Код на Python (через API), где реализованы все 4 варианта + вывод сравнения.

  ---

  Дополнительные моменты из чата:
   - Рекомендуется влиять на результат через системный промпт (например, указывать актуальную дату).
   - Модель не имеет автоматического доступа к интернету — для этого нужен инструмент web_search
     через Responses API.
   - К задаче нет жёстких требований — можно захардкодить одну задачу или предложить несколько на
     выбор.
