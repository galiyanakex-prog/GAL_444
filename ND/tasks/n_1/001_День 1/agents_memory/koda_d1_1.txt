❯ Краткое описание проекта

  AI Advent — практика работы с LLM API

  Учебный репозиторий курса AI Advent, последовательно знакомящий с работой через Groq API.

  Технологии: Python, Groq API, модель openai/gpt-oss-20b, python-dotenv.

  3 практических задания:

   1. День 1 — консольный чат-бот с историей диалога. Модель играет роль бортового помощника «Бублик»,
      пользователь — космический путешественник «Чебуратор». Реализованы роли system/user/assistant, обработка
      ошибок API.

   2. День 2 — управление форматом ответа. Один и тот же запрос отправляется дважды: без ограничений и с
      жёсткими правилами (формат, лимит 70 слов, max_completion_tokens, условие завершения). Результат —
      наглядное сравнение.

   3. День 3 — сравнение способов рассуждения. Одна логическая задача решается четырьмя методами (прямой
      запрос, пошаговое решение, генерация промпта моделью, имитация экспертов) с автоматическим сравнением
      результатов.

  Цель: понять, как формулировка промпта и параметры API влияют на поведение языковой модели.

  План реализации

  Файл: 02_День 2/Den_2_Kod.py

  Структура:
   1. Функция `send_request(user_input, mode)` — один вызов API с тремя режимами:
     - mode="free" — без ограничений
     - mode="limited" — с ограничениями (JSON-формат, длина, stop-инструкция)
     - mode="compare" — оба варианта рядом

   2. Ограничения для `mode="limited"`:
     - Системный промпт: Ответь в формате JSON с полями: title, summary, key_points (массив из 3 элементов)
     - Ограничение длины: Не более 10 слов
     - Stop-инструкция: Не добавляй пояснений после JSON

   3. Интерфейс:
     - Последовательный ввод: сначала запрос, потом выбор режима (1/2/3)
     - Или CLI-флаги через argparse

   4. Вывод:
     - Режим 1: один ответ
     - Режим 2: один ответ с ограничениями
     - Режим 3: два блока рядом для сравнения

  Ключевые отличия от образца:
   - Используем requests + routerai.ru вместо Groq SDK
   - JSON-формат вместо маркированного списка (как советовал Алексей в чате)
   - argparse для флагов вместо последовательного ввода
