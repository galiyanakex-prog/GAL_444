# День 1 — первый запрос к LLM через API

Первое практическое задание курса AI Advent по работе с большими языковыми моделями через API.

## Задание

Написать минимальный код, который:

- отправляет запрос в LLM через API;
- получает ответ модели;
- выводит результат в консоль.

## Результат

Создан консольный чат-бот, который обращается к модели `stepfun/step-3.5-flash` через `routerai.ru` API, выводит ответы и сохраняет историю текущего диалога.

## Что реализовано

- загрузка API-ключа из переменной окружения через `dotenv`;
- подключение к `routerai.ru` API через `requests`;
- отправка сообщений языковой модели;
- использование ролей `system`, `user` и `assistant`;
- настройка персонажа через системный промпт;
- сохранение истории диалога во время работы программы;
- обработка пустого пользовательского ввода;
- обработка ошибок API (HTTP, сетевые, неверный формат ответа);
- завершение программы командой `выход`.

## Как работает программа

### Системный промпт

Первым элементом истории создаётся сообщение с ролью `system`:

```python
messages = [
    {
        "role": "system",
        "content": "Ты полезный ассистент. Отвечай на русском языке.",
    }
]
```

Системный промпт определяет роль модели, контекст общения и язык ответа.

### История диалога

Перед каждым запросом сообщение пользователя добавляется в список `messages` с ролью `user`:

```python
messages.append({"role": "user", "content": user_input})
```

После успешного ответа результат модели добавляется с ролью `assistant`:

```python
messages.append({"role": "assistant", "content": bot_response})
```

В результате формируется последовательность:

```text
system → user → assistant → user → assistant
```

При следующем запросе модель получает весь накопленный диалог и может учитывать предыдущие сообщения. История хранится только в памяти и удаляется после завершения программы.

### Запрос к модели

```python
response = requests.post(url, headers=headers, json=data, timeout=60)
```

Используемые параметры:

- `model` — модель, которая обрабатывает запрос (`stepfun/step-3.5-flash`);
- `messages` — системный промпт и история диалога;
- `timeout` — ограничение времени ожидания ответа (60 секунд).

### Обработка ошибок

Если переменная `API_KEY` отсутствует, программа завершается с понятным сообщением.

Ошибки API перехватываются в блоке `try/except`:

- `requests.exceptions.HTTPError` — ошибки HTTP (неверный ключ, недоступность сервиса);
- `requests.exceptions.RequestException` — сетевые ошибки (нет соединения, таймаут);
- `KeyError`, `IndexError`, `ValueError` — ошибки разбора ответа (неожиданный формат JSON).

Если модель не ответила, последнее сообщение пользователя удаляется из истории:

```python
except Exception as error:
    messages.pop()
    print(f"Ошибка при обращении к API: {error}\n")
```

Так в истории не остаётся запроса без соответствующего ответа модели.

## Подготовка к запуску

Добавьте `API_KEY` в корневой файл `.env`:

```env
API_KEY=ваш_ключ_от_routerai
```

## Запуск

Из корня репозитория выполните:

```bash
python "001_День 1/Den_1_Kod.py"
```

После запуска появится приглашение:

```text
🤖 Чат-бот на RouterAI
Введите «выход» для завершения.

Вы:
```

Пример диалога:

```text
Вы: Как тебя зовут?
Бот: Я полезный ассистент. Чем могу помочь?
```

Для завершения программы введите `выход`.
