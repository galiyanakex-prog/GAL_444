🔥 Задача 31. Ассистент разработчика

Сделайте ваш WIKI
👉  WIKI - база знаний о вашем проекте (папка с файлами, которые полностью, подробнейшим образом описывают каждую часть проекта и сам проект в целом (со всеми взаимосвязями и перекрёстными ссылками), его правила).
👉 Все данные из README переносим в WIKI (каждый раздел - это отдельный файл.
👉 в основном файле WIKI содержится перечисление всей документации проекта со ссылками на конкретные файлы, а затем краткое их описаеие .
👉 В README остаётся только краткое, общее описание проекта и ссылкой на WIKI

Используйте RAG для подключения к документации вашего проекта:

👉 WIKI
👉README
👉Код

Через MCP подключите к AI-9 помошника по проекту  проекту:

👉 получение текущей git-ветки
👉 список файлов, diff

Реализуйте команду:

👉 /help — ассистент отвечает на вопросы о проекте
👉 использует документацию и контекст проекта

Минимальный результат:

👉 README + docs в RAG
👉 MCP
👉 /help отвечает на вопросы о структуре проекта

🔥 Задача 34. Ассистент для работы с файлами проекта

Сделайте ассистента, который активно работает с файлами, а не просто отвечает текстом.

Через MCP или доступный вам tooling ассистент должен уметь:

👉 читать файлы проекта
👉 искать информацию по нескольким файлам
👉 анализировать содержимое
👉 создавать или изменять файлы (это основная часть функционала самого AI_9 - отдельный слой с правилами безопасности, инвариантами и режимами согласования и выполнения действий)

Примеры сценариев (реализуйте минимум 2):

👉 найти все места, где используется определённый компонент / API
👉 обновить документацию на основе изменений в коде
👉 сгенерировать или обновить файлы документации (WIKI / README / ADR / changelog)
👉 проверить соответствие файлов правилам или инвариантам
👉 подготовить diff или список изменений

Важно:

👉 ассистент сам инициирует работу с файлами
👉 вы задаёте задачу на уровне цели, а не “открой файл X”

Минимальный результат:

👉 ассистент работает минимум с 2–3 файлами
👉 изменения сохраняются или выводятся как diff
👉 результат можно воспроизвести повторно

Результат:

AI-ассистент, который выполняет реальные операции с файлами проекта
