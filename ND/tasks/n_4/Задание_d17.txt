Руководитель проекта (куратор): Алексей Гладков (нужно следовать его указаниям).

Реализуйте свой MCP-сервер вокруг любого API (сделано на vps - MCP_SERVER_URL = "http://91.188.212.77:8000/mcp")

Сделайте:

1.👉 регистрацию инструмента (сделано на vps - Зарегистрирован инструмент:
```python
@mcp.tool()
def get_time(timezone_name: str = "UTC") -> str:
```
Имя инструмента:
```text
get_time
```)

2.👉 описание входных параметров (сделано на vps - Инструмент принимает параметр:
```text
timezone_name
```
Он задаёт часовой пояс в формате IANA, например:
```text
UTC
Europe/Moscow
Europe/London
Asia/Tokyo
```
Значение по умолчанию:
```text
UTC
```)

3.👉 возврат результата (сделано на vps - Инструмент возвращает текущее время в указанном часовом поясе в формате ISO 8601:

```text
2026-09-27T13:00:00+03:00
)


4. Подключите инструмент к своему агенту и:

4.1👉 вызовите его из приложения
4.2👉 получите и используйте результат

Результат:

Агент делает вызов к MCP-инструменту и получает результат
