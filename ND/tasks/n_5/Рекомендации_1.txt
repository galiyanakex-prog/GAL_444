## Архитектура БД
Рекомендую такую схему:
- `documents`: `doc_id`, `source`, `title`, `path`, `type`.
- `chunks`: `chunk_id`, `doc_id`, `strategy`, `section`, `chunk_index`, `text`, `char_len`, `token_len`.
- `embeddings`: `chunk_id`, `model_name`, `vector_blob` или `vector_json`, `created_at`.

Такой вариант позволит хранить обе стратегии параллельно и потом сравнивать их на одном и том же корпусе. SQLite это нормально поддерживает как локальное хранилище для прототипа. [1][4]

## Chunking-стратегии
**Фиксированный размер**:
- Плюс: просто реализовать, легко масштабировать.
- Минус: может резать мысль или кодовый блок посередине.

**Структурный chunking**:
- Плюс: лучше сохраняет смысл разделов и границы файлов.
- Минус: размеры чанков получаются неравномерными, иногда слишком длинными или слишком короткими.

Хорошая практика — для фиксированного chunking добавить overlap, а для структурного при необходимости дополнительно дробить очень большие разделы. Это поможет сохранить контекст и не потерять информацию на границах.

## Эмбеддинги и индекс
Для эмбеддингов подойдёт sentence-transformers: модель превращает текст в фиксированный вектор и хорошо подходит для semantic search. Если задача позже расширится, ту же экосистему можно использовать и для reranking, но на текущем шаге это не обязательно.

## Что сравнивать
Сделай сравнение по таким пунктам:
- Количество чанков.
- Средний размер чанка.
- Количество чанков, содержащих полный смысловой блок.
- Качество результатов на 5–10 тестовых запросах.
- Удобство ручной проверки источников.

Минимально достаточно показать, что структурный chunking лучше сохраняет смысл, а фиксированный — проще и стабильнее по размеру.

## SQLite-схема
Рекомендую 3 таблицы:

```sql
documents(
  doc_id TEXT PRIMARY KEY,
  source TEXT,
  title TEXT,
  path TEXT,
  doc_type TEXT
)

chunks(
  chunk_id TEXT PRIMARY KEY,
  doc_id TEXT,
  strategy TEXT,
  section TEXT,
  chunk_index INTEGER,
  text TEXT,
  char_len INTEGER,
  token_len INTEGER
)

embeddings(
  chunk_id TEXT,
  model_name TEXT,
  vector TEXT,
  dim INTEGER,
  created_at TEXT
)
```

Для прототипа вектор можно хранить как JSON-массив в `TEXT`; для более строгого варианта — как BLOB. [1][2][3]

## Косинусный поиск
Если embeddings уже L2-нормализованы, косинусная близость становится особенно удобной:
$$
\cos(\theta) = \frac{a \cdot b}{\|a\| \|b\|}
$$
При unit-length векторах это сводится к скалярному произведению, что упрощает реализацию. Ollama пишет, что `/api/embed` возвращает L2-normalized vectors, а для семантического поиска рекомендует cosine similarity. [3][1]

Практически ты можешь:
- взять embedding запроса;
- загрузить все embeddings из SQLite;
- посчитать cosine similarity в Python;
- отсортировать по убыванию;
- взять top-N чанков;
- передать их в агент. [1][2][5]

```bash
  -d '{"model":"embeddinggemma","input":"Hello world"}'
```

Модель позиционируется как компактная embedding-модель для search/retrieval. [6][1]

У `qwen3-embedding` есть несколько размеров, включая `0.6b`, `4b` и `8b`, поэтому её удобно подбирать под ресурсы. [7]

```python
from __future__ import annotations

import sqlite3
from pathlib import Path


SCHEMA_SQL = """
PRAGMA journal_mode=WAL;
PRAGMA foreign_keys=ON;

CREATE TABLE IF NOT EXISTS documents (
    doc_id TEXT PRIMARY KEY,
    source TEXT NOT NULL,
    title TEXT NOT NULL,
    path TEXT NOT NULL,
    doc_type TEXT NOT NULL,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS chunks (
    chunk_id TEXT PRIMARY KEY,
    doc_id TEXT NOT NULL,
    strategy TEXT NOT NULL,
    section TEXT,
    chunk_index INTEGER NOT NULL,
    text TEXT NOT NULL,
    char_len INTEGER NOT NULL,
    token_len INTEGER,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (doc_id) REFERENCES documents(doc_id) ON DELETE CASCADE
);

CREATE TABLE IF NOT EXISTS embeddings (
    chunk_id TEXT NOT NULL,
    model_name TEXT NOT NULL,
    vector TEXT NOT NULL,
    dim INTEGER NOT NULL,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (chunk_id, model_name),
    FOREIGN KEY (chunk_id) REFERENCES chunks(chunk_id) ON DELETE CASCADE
);

CREATE INDEX IF NOT EXISTS idx_chunks_doc_id ON chunks(doc_id);
CREATE INDEX IF NOT EXISTS idx_chunks_strategy ON chunks(strategy);
CREATE INDEX IF NOT EXISTS idx_embeddings_model_name ON embeddings(model_name);
"""


def connect_db(db_path: str | Path) -> sqlite3.Connection:
    conn = sqlite3.connect(str(db_path))
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA foreign_keys=ON;")
    return conn


def init_db(db_path: str | Path) -> None:
    Path(db_path).parent.mkdir(parents=True, exist_ok=True)
    with connect_db(db_path) as conn:
        conn.executescript(SCHEMA_SQL)
        conn.commit()
```

## `ollama_client.py`
```python
from __future__ import annotations

from dataclasses import dataclass
from typing import Iterable

import ollama


@dataclass(frozen=True)
class OllamaEmbeddingClient:
    model: str = "embeddinggemma"

    def embed_one(self, text: str) -> list[float]:
        response = ollama.embed(model=self.model, input=text)
        return list(response["embeddings"][0])

    def embed_many(self, texts: Iterable[str]) -> list[list[float]]:
        items = list(texts)
        response = ollama.embed(model=self.model, input=items)
        return [list(vec) for vec in response["embeddings"]]
```

## `repository.py`
```python
from __future__ import annotations

import json
import sqlite3
from dataclasses import dataclass
from pathlib import Path
from typing import Iterable

from rag_index.indexing.schema import connect_db, init_db


@dataclass
class DocumentRow:
    doc_id: str
    source: str
    title: str
    path: str
    doc_type: str


@dataclass
class ChunkRow:
    chunk_id: str
    doc_id: str
    strategy: str
    section: str | None
    chunk_index: int
    text: str
    char_len: int
    token_len: int | None = None


@dataclass
class EmbeddingRow:
    chunk_id: str
    model_name: str
    vector: list[float]
    dim: int


class Repository:
    def __init__(self, db_path: str | Path):
        self.db_path = Path(db_path)
        init_db(self.db_path)

    def _conn(self) -> sqlite3.Connection:
        return connect_db(self.db_path)

    def upsert_document(self, row: DocumentRow) -> None:
        sql = """
        INSERT INTO documents (doc_id, source, title, path, doc_type)
        VALUES (?, ?, ?, ?, ?)
        ON CONFLICT(doc_id) DO UPDATE SET
            source=excluded.source,
            title=excluded.title,
            path=excluded.path,
            doc_type=excluded.doc_type
        """
        with self._conn() as conn:
            conn.execute(sql, (row.doc_id, row.source, row.title, row.path, row.doc_type))
            conn.commit()

    def upsert_chunks(self, rows: Iterable[ChunkRow]) -> None:
        sql = """
        INSERT INTO chunks (
            chunk_id, doc_id, strategy, section, chunk_index, text, char_len, token_len
        ) VALUES (?, ?, ?, ?, ?, ?, ?, ?)
        ON CONFLICT(chunk_id) DO UPDATE SET
            doc_id=excluded.doc_id,
            strategy=excluded.strategy,
            section=excluded.section,
            chunk_index=excluded.chunk_index,
            text=excluded.text,
            char_len=excluded.char_len,
            token_len=excluded.token_len
        """
        payload = [
            (
                r.chunk_id,
                r.doc_id,
                r.strategy,
                r.section,
                r.chunk_index,
                r.text,
                r.char_len,
                r.token_len,
            )
            for r in rows
        ]
        with self._conn() as conn:
            conn.executemany(sql, payload)
            conn.commit()

    def upsert_embeddings(self, rows: Iterable[EmbeddingRow]) -> None:
        sql = """
        INSERT INTO embeddings (chunk_id, model_name, vector, dim)
        VALUES (?, ?, ?, ?)
        ON CONFLICT(chunk_id, model_name) DO UPDATE SET
            vector=excluded.vector,
            dim=excluded.dim
        """
        payload = [
            (r.chunk_id, r.model_name, json.dumps(r.vector), r.dim)
            for r in rows
        ]
        with self._conn() as conn:
            conn.executemany(sql, payload)
            conn.commit()

    def fetch_all_embeddings(self, model_name: str) -> list[sqlite3.Row]:
        sql = """
        SELECT c.chunk_id, c.doc_id, c.strategy, c.section, c.chunk_index, c.text,
               c.char_len, c.token_len, d.title, d.source, d.path, e.vector, e.dim
        FROM chunks c
        JOIN documents d ON d.doc_id = c.doc_id
        JOIN embeddings e ON e.chunk_id = c.chunk_id
        WHERE e.model_name = ?
        ORDER BY c.doc_id, c.chunk_index
        """
        with self._conn() as conn:
            conn.row_factory = sqlite3.Row
            cur = conn.execute(sql, (model_name,))
            return cur.fetchall()

    def count_documents(self) -> int:
        with self._conn() as conn:
            cur = conn.execute("SELECT COUNT(*) FROM documents")
            return int(cur.fetchone()[0])

    def count_chunks(self) -> int:
        with self._conn() as conn:
            cur = conn.execute("SELECT COUNT(*) FROM chunks")
            return int(cur.fetchone()[0])

    def count_embeddings(self) -> int:
        with self._conn() as conn:
            cur = conn.execute("SELECT COUNT(*) FROM embeddings")
            return int(cur.fetchone()[0])
```

## `retriever.py`
```python
from __future__ import annotations

import json
from dataclasses import dataclass

import numpy as np

from rag_index.indexing.repository import Repository
from rag_index.models.ollama_client import OllamaEmbeddingClient


@dataclass
class RetrievedChunk:
    chunk_id: str
    doc_id: str
    title: str
    source: str
    path: str
    section: str | None
    chunk_index: int
    text: str
    score: float


def cosine_similarity(a: np.ndarray, b: np.ndarray) -> float:
    denom = (np.linalg.norm(a) * np.linalg.norm(b))
    if denom == 0:
        return 0.0
    return float(np.dot(a, b) / denom)


class Retriever:
    def __init__(
        self,
        repository: Repository,
        embedder: OllamaEmbeddingClient,
        model_name: str,
    ):
        self.repository = repository
        self.embedder = embedder
        self.model_name = model_name

    def search(self, query: str, top_k: int = 5) -> list[RetrievedChunk]:
        query_vec = np.array(self.embedder.embed_one(query), dtype=np.float32)
        rows = self.repository.fetch_all_embeddings(self.model_name)

        scored: list[RetrievedChunk] = []
        for row in rows:
            vec = np.array(json.loads(row["vector"]), dtype=np.float32)
            score = cosine_similarity(query_vec, vec)
            scored.append(
                RetrievedChunk(
                    chunk_id=row["chunk_id"],
                    doc_id=row["doc_id"],
                    title=row["title"],
                    source=row["source"],
                    path=row["path"],
                    section=row["section"],
                    chunk_index=int(row["chunk_index"]),
                    text=row["text"],
                    score=score,
                )
            )

        scored.sort(key=lambda x: x.score, reverse=True)
        return scored[:top_k]
```

```python
from __future__ import annotations

import re
from dataclasses import dataclass
from uuid import uuid4

from rag_index.chunking.base import Chunk


@dataclass
class FixedSizeChunker:
    chunk_size: int = 1000
    overlap: int = 150
    strategy_name: str = "fixed_size"

    def chunk(self, doc_id: str, text: str, title: str | None = None) -> list[Chunk]:
        cleaned = re.sub(r"\s+", " ", text).strip()
        if not cleaned:
            return []

        step = max(1, self.chunk_size - self.overlap)
        chunks: list[Chunk] = []

        start = 0
        idx = 0
        while start < len(cleaned):
            end = min(len(cleaned), start + self.chunk_size)
            piece = cleaned[start:end].strip()
            if piece:
                chunks.append(
                    Chunk(
                        chunk_id=str(uuid4()),
                        doc_id=doc_id,
                        strategy=self.strategy_name,
                        section=title,
                        chunk_index=idx,
                        text=piece,
                        char_len=len(piece),
                        token_len=None,
                    )
                )
                idx += 1
            if end >= len(cleaned):
                break
            start += step

        return chunks
```

## `chunking/structured.py`
```python
from __future__ import annotations

import re
from dataclasses import dataclass
from uuid import uuid4

from rag_index.chunking.base import Chunk


@dataclass
class StructuredChunker:
    max_chunk_size: int = 1200
    overlap_tail_chars: int = 120
    strategy_name: str = "structured"

    heading_pattern: re.Pattern[str] = re.compile(
        r"^(#{1,6}\s+.+|[A-ZА-Я0-9][^\n]{0,120}:)$", re.MULTILINE
    )

    def chunk(self, doc_id: str, text: str, title: str | None = None) -> list[Chunk]:
        text = text.strip()
        if not text:
            return []

        blocks = self._split_by_headings(text)
        chunks: list[Chunk] = []
        idx = 0

        for section, block in blocks:
            for piece in self._split_block(block, self.max_chunk_size):
                if not piece.strip():
                    continue
                chunks.append(
                    Chunk(
                        chunk_id=str(uuid4()),
                        doc_id=doc_id,
                        strategy=self.strategy_name,
                        section=section or title,
                        chunk_index=idx,
                        text=piece.strip(),
                        char_len=len(piece.strip()),
                        token_len=None,
                    )
                )
                idx += 1

        return chunks

    def _split_by_headings(self, text: str) -> list[tuple[str | None, str]]:
        lines = text.splitlines()
        blocks: list[tuple[str | None, str]] = []
        current_section: str | None = None
        current_lines: list[str] = []

        def flush() -> None:
            nonlocal current_lines, current_section
            block_text = "\n".join(current_lines).strip()
            if block_text:
                blocks.append((current_section, block_text))
            current_lines = []

        for line in lines:
            if self.heading_pattern.match(line.strip()):
                flush()
                current_section = line.strip().lstrip("#").strip().rstrip(":")
                continue
            current_lines.append(line)

        flush()
        if not blocks:
            return [(None, text)]
        return blocks

    def _split_block(self, block: str, max_size: int) -> list[str]:
        if len(block) <= max_size:
            return [block]

        parts: list[str] = []
        start = 0

        while start < len(block):
            end = min(len(block), start + max_size)
            if end < len(block):
                cut = max(block.rfind("\n\n", start, end), block.rfind("\n", start, end))
                if cut > start + max_size // 2:
                    end = cut
            piece = block[start:end].strip()
            if piece:
                parts.append(piece)
            if end >= len(block):
                break
            start = max(0, end - self.overlap_tail_chars)

        return parts
```

## Что здесь заложено
- `Chunk` — единая структура для обоих chunking-режимов.
- `FixedSizeChunker` — простой baseline с overlap.
- `StructuredChunker` — сначала ищет заголовки, потом дробит длинные блоки.
- В `structured.py` я использовал эвристику для Markdown-заголовков и заголовков вида “SECTION:”, чтобы твои README/статьи/техтексты делились осмысленно.
Такой подход соответствует рекомендациям для RAG: структурные границы лучше сохраняют смысл, а фиксированный размер с overlap помогает не терять контекст. [1][2]

## Как лучше использовать
Обычно ты будешь делать так:
1. Сначала прогонять документ через `StructuredChunker`.
2. Если нужен контроль размера — дополнительно ограничивать слишком большие блоки.
3. Для сравнения в отчёте параллельно считать `FixedSizeChunker`.
4. Потом сохранять оба результата в SQLite с разными `strategy`.

```python
from rag_index.indexing.repository import (
    ChunkRow,
    DocumentRow,
    EmbeddingRow,
    Repository,
)
from rag_index.models.ollama_client import OllamaEmbeddingClient


@dataclass(frozen=True)
class SourceDocument:
    doc_id: str
    source: str
    title: str
    path: str
    doc_type: str
    text: str


class Indexer:
    def __init__(
        self,
        repository: Repository,
        embedder: OllamaEmbeddingClient,
        model_name: str,
    ):
        self.repository = repository
        self.embedder = embedder
        self.model_name = model_name
        self.fixed_chunker = FixedSizeChunker()
        self.structured_chunker = StructuredChunker()

    def index_documents(self, documents: Iterable[SourceDocument]) -> None:
        for doc in documents:
            self.repository.upsert_document(
                DocumentRow(
                    doc_id=doc.doc_id,
                    source=doc.source,
                    title=doc.title,
                    path=doc.path,
                    doc_type=doc.doc_type,
                )
            )

            fixed_chunks = self.fixed_chunker.chunk(doc.doc_id, doc.text, title=doc.title)
            structured_chunks = self.structured_chunker.chunk(doc.doc_id, doc.text, title=doc.title)

            all_chunks = fixed_chunks + structured_chunks
            if not all_chunks:
                continue

            self.repository.upsert_chunks(
                [
                    ChunkRow(
                        chunk_id=c.chunk_id,
                        doc_id=c.doc_id,
                        strategy=c.strategy,
                        section=c.section,
                        chunk_index=c.chunk_index,
                        text=c.text,
                        char_len=c.char_len,
                        token_len=c.token_len,
                    )
                    for c in all_chunks
                ]
            )

            embeddings = self.embedder.embed_many([c.text for c in all_chunks])
            self.repository.upsert_embeddings(
                [
                    EmbeddingRow(
                        chunk_id=c.chunk_id,
                        model_name=self.model_name,
                        vector=vec,
                        dim=len(vec),
                    )
                    for c, vec in zip(all_chunks, embeddings)
                ]
            )

    def index_single_strategy(
        self,
        documents: Iterable[SourceDocument],
        strategy: str = "fixed_size",
    ) -> None:
        if strategy == "fixed_size":
            chunker = self.fixed_chunker
        elif strategy == "structured":
            chunker = self.structured_chunker
        else:
            raise ValueError(f"Unknown strategy: {strategy}")

        for doc in documents:
            self.repository.upsert_document(
                DocumentRow(
                    doc_id=doc.doc_id,
                    source=doc.source,
                    title=doc.title,
                    path=doc.path,
                    doc_type=doc.doc_type,
                )
            )

            chunks = chunker.chunk(doc.doc_id, doc.text, title=doc.title)
            if not chunks:
                continue

            self.repository.upsert_chunks(
                [
                    ChunkRow(
                        chunk_id=c.chunk_id,
                        doc_id=c.doc_id,
                        strategy=c.strategy,
                        section=c.section,
                        chunk_index=c.chunk_index,
                        text=c.text,
                        char_len=c.char_len,
                        token_len=c.token_len,
                    )
                    for c in chunks
                ]
            )

            embeddings = self.embedder.embed_many([c.text for c in chunks])
            self.repository.upsert_embeddings(
                [
                    EmbeddingRow(
                        chunk_id=c.chunk_id,
                        model_name=self.model_name,
                        vector=vec,
                        dim=len(vec),
                    )
                    for c, vec in zip(chunks, embeddings)
                ]
            )
```

## Что здесь важно
- `SourceDocument` — минимальный контейнер для входного текста.
- `index_documents()` индексирует оба chunking-режима сразу, что удобно для сравнения.
- `index_single_strategy()` полезен, если захочешь отдельно прогонять baseline и structured variant.
- `embed_many()` лучше, чем эмбеддить по одному чанку, потому что Ollama поддерживает batch embeddings. [1][2][3]

```python
from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

import pymupdf

from rag_index.loaders.base import LoadedDocument


@dataclass
class PdfLoader:
    def load(self, path: str | Path) -> LoadedDocument:
        p = Path(path)
        text_parts: list[str] = []

        doc = pymupdf.open(str(p))
        try:
            for page in doc:
                text_parts.append(page.get_text("text"))
        finally:
            doc.close()

        text = "\n".join(text_parts)
        return LoadedDocument(
            doc_id=self._make_doc_id(p),
            source=str(p),
            title=p.stem,
            path=str(p),
            doc_type="pdf",
            text=text,
        )

    def _make_doc_id(self, p: Path) -> str:
        return str(p.resolve())
```

```python
from __future__ import annotations

import argparse
from pathlib import Path

from rag_index.indexing.indexer import Indexer, SourceDocument
from rag_index.indexing.repository import Repository
from rag_index.models.ollama_client import OllamaEmbeddingClient
from rag_index.loaders.code_loader import CodeLoader
from rag_index.loaders.markdown_loader import MarkdownLoader
from rag_index.loaders.pdf_loader import PdfLoader


def load_document(path: Path) -> SourceDocument:
    suffix = path.suffix.lower()

    if suffix in {".md", ".markdown"}:
        loader = MarkdownLoader()
    elif suffix == ".pdf":
        loader = PdfLoader()
    else:
        loader = CodeLoader()

    loaded = loader.load(path)
    return SourceDocument(
        doc_id=loaded.doc_id,
        source=loaded.source,
        title=loaded.title,
        path=loaded.path,
        doc_type=loaded.doc_type,
        text=loaded.text,
    )


def iter_files(input_dir: Path) -> list[Path]:
    allowed = {".md", ".markdown", ".pdf", ".py", ".js", ".ts", ".java", ".go", ".txt", ".json", ".yaml", ".yml"}
    return [p for p in input_dir.rglob("*") if p.is_file() and p.suffix.lower() in allowed]


def main() -> None:
    parser = argparse.ArgumentParser(description="Build local RAG index in SQLite")
    parser.add_argument("--input-dir", required=True, help="Directory with source documents")
    parser.add_argument("--db-path", default="data/index/rag.db", help="SQLite database path")
    parser.add_argument("--model", default="embeddinggemma", help="Ollama embedding model")
    args = parser.parse_args()

    input_dir = Path(args.input_dir)
    db_path = Path(args.db_path)

    repository = Repository(db_path)
    embedder = OllamaEmbeddingClient(model=args.model)
    indexer = Indexer(repository=repository, embedder=embedder, model_name=args.model)

    documents = [load_document(p) for p in iter_files(input_dir)]
    indexer.index_documents(documents)

    print(f"Indexed documents: {repository.count_documents()}")
    print(f"Indexed chunks: {repository.count_chunks()}")
    print(f"Indexed embeddings: {repository.count_embeddings()}")


if __name__ == "__main__":
    main()
```

```python
import argparse

        print(f"source: {item.source}")
        print(f"section: {item.section}")
        print(f"chunk_id: {item.chunk_id}")
```

## `scripts/compare_chunking.py`
```python
from __future__ import annotations

import argparse
import csv
from dataclasses import asdict, dataclass
from pathlib import Path

from rag_index.chunking.fixed_size import FixedSizeChunker
from rag_index.chunking.structured import StructuredChunker
from rag_index.loaders.code_loader import CodeLoader
from rag_index.loaders.markdown_loader import MarkdownLoader
from rag_index.loaders.pdf_loader import PdfLoader


@dataclass
class StrategyStats:
    strategy: str
    documents: int
    chunks: int
    avg_chunk_len: float
    min_chunk_len: int
    max_chunk_len: int


def load_text(path: Path):
    suffix = path.suffix.lower()
    if suffix in {".md", ".markdown"}:
        loader = MarkdownLoader()
    elif suffix == ".pdf":
        loader = PdfLoader()
    else:
        loader = CodeLoader()
    return loader.load(path)


def iter_files(input_dir: Path) -> list[Path]:
    allowed = {".md", ".markdown", ".pdf", ".py", ".js", ".ts", ".java", ".go", ".txt", ".json", ".yaml", ".yml"}
    return [p for p in input_dir.rglob("*") if p.is_file() and p.suffix.lower() in allowed]


def measure(strategy: str, paths: list[Path]) -> StrategyStats:
    if strategy == "fixed_size":
        chunker = FixedSizeChunker()
    elif strategy == "structured":
        chunker = StructuredChunker()
    else:
        raise ValueError(strategy)

    lengths: list[int] = []
    doc_count = 0

    for path in paths:
        loaded = load_text(path)
        doc_count += 1
        chunks = chunker.chunk(loaded.doc_id, loaded.text, title=loaded.title)
        lengths.extend([c.char_len for c in chunks])

    if not lengths:
        return StrategyStats(strategy, doc_count, 0, 0.0, 0, 0)

    return StrategyStats(
        strategy=strategy,
        documents=doc_count,
        chunks=len(lengths),
        avg_chunk_len=sum(lengths) / len(lengths),
        min_chunk_len=min(lengths),
        max_chunk_len=max(lengths),
    )


def main() -> None:
    parser = argparse.ArgumentParser(description="Compare chunking strategies")
    parser.add_argument("--input-dir", required=True, help="Directory with source documents")
    parser.add_argument("--out-csv", default="data/processed/chunking_comparison.csv", help="Output CSV path")
    args = parser.parse_args()

    input_dir = Path(args.input_dir)
    out_csv = Path(args.out_csv)
    out_csv.parent.mkdir(parents=True, exist_ok=True)

    paths = iter_files(input_dir)
    results = [
        measure("fixed_size", paths),
        measure("structured", paths),
    ]

    with out_csv.open("w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=list(asdict(results[0]).keys()))
        writer.writeheader()
        for row in results:
            writer.writerow(asdict(row))

    for row in results:
        print(asdict(row))


if __name__ == "__main__":
    main()
```

Покажи evaluation/metrics.py и compare.py

Ниже — `evaluation/metrics.py` и `evaluation/compare.py`, чтобы сравнивать стратегии chunking по простым и понятным метрикам. Для RAG это удобно, потому что embeddings в Ollama уже можно искать через cosine similarity, а сравнение стратегий лучше строить на количестве чанков, средней длине и качестве top-k retrieval. [1][2]

## `evaluation/metrics.py`
```python
from __future__ import annotations

from dataclasses import dataclass
from typing import Iterable

import numpy as np


@dataclass(frozen=True)
class ChunkingMetrics:
    strategy: str
    documents: int
    chunks: int
    avg_chunk_len: float
    min_chunk_len: int
    max_chunk_len: int
    std_chunk_len: float


@dataclass(frozen=True)
class RetrievalMetrics:
    total_queries: int
    hit_rate_at_1: float
    hit_rate_at_3: float
    hit_rate_at_5: float
    mean_reciprocal_rank: float


def chunk_length_metrics(strategy: str, lengths: Iterable[int], documents: int) -> ChunkingMetrics:
    arr = np.array(list(lengths), dtype=np.float32)
    if arr.size == 0:
        return ChunkingMetrics(strategy, documents, 0, 0.0, 0, 0, 0.0)

    return ChunkingMetrics(
        strategy=strategy,
        documents=documents,
        chunks=int(arr.size),
        avg_chunk_len=float(arr.mean()),
        min_chunk_len=int(arr.min()),
        max_chunk_len=int(arr.max()),
        std_chunk_len=float(arr.std(ddof=0)),
    )


def hit_rate_at_k(ranks: list[int | None], k: int) -> float:
    if not ranks:
        return 0.0
    hits = sum(1 for r in ranks if r is not None and r <= k)
    return hits / len(ranks)


def mean_reciprocal_rank(ranks: list[int | None]) -> float:
    if not ranks:
        return 0.0
    values = [(1.0 / r) for r in ranks if r is not None and r > 0]
    return float(sum(values) / len(ranks)) if ranks else 0.0


def retrieval_metrics(ranks: list[int | None]) -> RetrievalMetrics:
    return RetrievalMetrics(
        total_queries=len(ranks),
        hit_rate_at_1=hit_rate_at_k(ranks, 1),
        hit_rate_at_3=hit_rate_at_k(ranks, 3),
        hit_rate_at_5=hit_rate_at_k(ranks, 5),
        mean_reciprocal_rank=mean_reciprocal_rank(ranks),
    )
```

## `evaluation/compare.py`
```python
from __future__ import annotations

import csv
from dataclasses import asdict
from pathlib import Path

from rag_index.chunking.fixed_size import FixedSizeChunker
from rag_index.chunking.structured import StructuredChunker
from rag_index.evaluation.metrics import chunk_length_metrics
from rag_index.loaders.code_loader import CodeLoader
from rag_index.loaders.markdown_loader import MarkdownLoader
from rag_index.loaders.pdf_loader import PdfLoader


def load_text(path: Path):
    suffix = path.suffix.lower()
    if suffix in {".md", ".markdown"}:
        loader = MarkdownLoader()
    elif suffix == ".pdf":
        loader = PdfLoader()
    else:
        loader = CodeLoader()
    return loader.load(path)


def iter_files(input_dir: Path) -> list[Path]:
    allowed = {".md", ".markdown", ".pdf", ".py", ".js", ".ts", ".java", ".go", ".txt", ".json", ".yaml", ".yml"}
    return [p for p in input_dir.rglob("*") if p.is_file() and p.suffix.lower() in allowed]


def evaluate_strategy(strategy: str, paths: list[Path]):
    if strategy == "fixed_size":
        chunker = FixedSizeChunker()
    elif strategy == "structured":
        chunker = StructuredChunker()
    else:
        raise ValueError(strategy)

    lengths: list[int] = []
    docs = 0

    for path in paths:
        loaded = load_text(path)
        docs += 1
        chunks = chunker.chunk(loaded.doc_id, loaded.text, title=loaded.title)
        lengths.extend([c.char_len for c in chunks])

    return chunk_length_metrics(strategy=strategy, lengths=lengths, documents=docs)


def compare_strategies(input_dir: str, out_csv: str) -> None:
    root = Path(input_dir)
    paths = iter_files(root)

    results = [
        evaluate_strategy("fixed_size", paths),
        evaluate_strategy("structured", paths),
    ]

    out_path = Path(out_csv)
    out_path.parent.mkdir(parents=True, exist_ok=True)

    with out_path.open("w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=list(asdict(results[0]).keys()))
        writer.writeheader()
        for item in results:
            writer.writerow(asdict(item))

    for item in results:
        print(asdict(item))


if __name__ == "__main__":
    import argparse

    parser = argparse.ArgumentParser(description="Compare chunking strategies")
    parser.add_argument("--input-dir", required=True)
    parser.add_argument("--out-csv", default="data/processed/chunking_comparison.csv")
    args = parser.parse_args()

    compare_strategies(args.input_dir, args.out_csv)
```

Давай retrieval/cosine.py и main.py

Ниже — `retrieval/cosine.py` и `src/rag_index/__main__.py` для единой CLI-точки входа. Для cosine similarity я использую стандартную формулу через dot product и L2 norm, а для CLI — `argparse`, который в Python является рекомендованным стандартным инструментом для командной строки. [1][2]

## `retrieval/cosine.py`
```python
from __future__ import annotations

import numpy as np


def cosine_similarity(a: list[float] | np.ndarray, b: list[float] | np.ndarray) -> float:
    va = np.asarray(a, dtype=np.float32)
    vb = np.asarray(b, dtype=np.float32)

    denom = float(np.linalg.norm(va) * np.linalg.norm(vb))
    if denom == 0.0:
        return 0.0

    return float(np.dot(va, vb) / denom)


def cosine_distance(a: list[float] | np.ndarray, b: list[float] | np.ndarray) -> float:
    return 1.0 - cosine_similarity(a, b)
```

## `src/rag_index/__main__.py`
```python
from __future__ import annotations

import argparse
from pathlib import Path

from rag_index.evaluation.compare import compare_strategies
from rag_index.indexing.repository import Repository
from rag_index.models.ollama_client import OllamaEmbeddingClient
from rag_index.retrieval.retriever import Retriever


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(
        prog="rag-index",
        description="Local document indexing and retrieval for RAG",
    )
    sub = parser.add_subparsers(dest="command", required=True)

    p_search = sub.add_parser("search", help="Search indexed documents")
    p_search.add_argument("--db-path", default="data/index/rag.db")
    p_search.add_argument("--model", default="embeddinggemma")
    p_search.add_argument("--query", required=True)
    p_search.add_argument("--top-k", type=int, default=5)

    p_compare = sub.add_parser("compare", help="Compare chunking strategies")
    p_compare.add_argument("--input-dir", required=True)
    p_compare.add_argument("--out-csv", default="data/processed/chunking_comparison.csv")

    return parser


def main() -> None:
    parser = build_parser()
    args = parser.parse_args()

    if args.command == "search":
        repository = Repository(Path(args.db_path))
        embedder = OllamaEmbeddingClient(model=args.model)
        retriever = Retriever(repository=repository, embedder=embedder, model_name=args.model)
        results = retriever.search(args.query, top_k=args.top_k)

        for i, item in enumerate(results, start=1):
            print(f"\n#{i} score={item.score:.4f}")
            print(f"title: {item.title}")
            print(f"source: {item.source}")
            print(f"section: {item.section}")
            print(f"text: {item.text[:800]}")

    elif args.command == "compare":
        compare_strategies(args.input_dir, args.out_csv)


if __name__ == "__main__":
    main()
```

`cosine.py` выносит similarity в отдельный модуль, чтобы переиспользовать её и в `retriever.py`, и в тестах. `__main__.py` добавляет удобный запуск через `python -m rag_index search ...` или `python -m rag_index compare ...`, что обычно удобнее, чем отдельные скрипты. [2][1]

```python
from rag_index.chunking.fixed_size import FixedSizeChunker
from rag_index.chunking.structured import StructuredChunker


def test_fixed_size_chunker_returns_chunks():
    text = "a" * 2500
    chunker = FixedSizeChunker(chunk_size=1000, overlap=100)
    chunks = chunker.chunk("doc-1", text, title="Doc")
    assert len(chunks) >= 2
    assert all(c.strategy == "fixed_size" for c in chunks)


def test_fixed_size_chunker_respects_overlap():
    text = "abcdef" * 400
    chunker = FixedSizeChunker(chunk_size=500, overlap=50)
    chunks = chunker.chunk("doc-1", text, title="Doc")
    assert len(chunks) >= 2
    assert chunks[0].text[-50:] != ""
    assert chunks[1].text != ""


def test_structured_chunker_uses_headings():
    text = """
# Intro
This is intro text.

## Usage
This is usage text.

## API
This is API text.
""".strip()

    chunker = StructuredChunker(max_chunk_size=200)

    assert len(chunks) >= 3
    sections = [c.section for c in chunks]
    assert "Intro" in sections
    assert "Usage" in sections
    assert "API" in sections
```

## `src/rag_index/models/embeddings.py`
```python
from __future__ import annotations

from dataclasses import dataclass, field
from typing import Sequence


@dataclass(frozen=True)
class EmbeddingVector:
    values: list[float] = field(default_factory=list)

    @property
    def dim(self) -> int:
        return len(self.values)

    def to_list(self) -> list[float]:
        return list(self.values)

    @classmethod
    def from_sequence(cls, seq: Sequence[float]) -> "EmbeddingVector":
        return cls(values=[float(x) for x in seq])
```

## `models/ollama_client.py`
```python
from __future__ import annotations

from dataclasses import dataclass
from typing import Iterable

import ollama

from rag_index.config import settings


@dataclass(frozen=True)
class OllamaEmbeddingClient:
    model: str = settings.embedding_model
    host: str = settings.ollama_host

    def __post_init__(self) -> None:
        object.__setattr__(self, "_client", ollama.Client(host=self.host))

    def embed_one(self, text: str) -> list[float]:
        response = self._client.embed(model=self.model, input=text)
        return list(response["embeddings"][0])

    def embed_many(self, texts: Iterable[str]) -> list[list[float]]:
        items = list(texts)
        response = self._client.embed(model=self.model, input=items)
        return [list(vec) for vec in response["embeddings"]]
```

## `src/rag_index/evaluation/compare.py`
```python
from __future__ import annotations

import csv
from dataclasses import asdict
from pathlib import Path

from rag_index.chunking.fixed_size import FixedSizeChunker
from rag_index.chunking.structured import StructuredChunker
from rag_index.config import settings
from rag_index.evaluation.metrics import chunk_length_metrics
from rag_index.loaders.code_loader import CodeLoader
from rag_index.loaders.markdown_loader import MarkdownLoader
from rag_index.loaders.pdf_loader import PdfLoader


def load_text(path: Path):
    suffix = path.suffix.lower()
    if suffix in {".md", ".markdown"}:
        loader = MarkdownLoader()
    elif suffix == ".pdf":
        loader = PdfLoader()
    else:
        loader = CodeLoader()
    return loader.load(path)


def iter_files(input_dir: Path) -> list[Path]:
    allowed = {".md", ".markdown", ".pdf", ".py", ".js", ".ts", ".java", ".go", ".txt", ".json", ".yaml", ".yml"}
    return [p for p in input_dir.rglob("*") if p.is_file() and p.suffix.lower() in allowed]


def evaluate_strategy(strategy: str, paths: list[Path]):
    if strategy == "fixed_size":
        chunker = FixedSizeChunker(
            chunk_size=settings.fixed_chunk_size,
            overlap=settings.fixed_chunk_overlap,
        )
    elif strategy == "structured":
        chunker = StructuredChunker(
            max_chunk_size=settings.structured_max_chunk_size,
            overlap_tail_chars=settings.structured_overlap_tail_chars,
        )
    else:
        raise ValueError(strategy)

    lengths: list[int] = []
    docs = 0

    for path in paths:
        loaded = load_text(path)
        docs += 1
        chunks = chunker.chunk(loaded.doc_id, loaded.text, title=loaded.title)
        lengths.extend([c.char_len for c in chunks])

    return chunk_length_metrics(strategy=strategy, lengths=lengths, documents=docs)


def compare_strategies(input_dir: str, out_csv: str) -> None:
    root = Path(input_dir)
    paths = iter_files(root)

    results = [
        evaluate_strategy("fixed_size", paths),
        evaluate_strategy("structured", paths),
    ]

    out_path = Path(out_csv)
    out_path.parent.mkdir(parents=True, exist_ok=True)

    with out_path.open("w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=list(asdict(results[0]).keys()))
        writer.writeheader()
        for item in results:
            writer.writerow(asdict(item))

    for item in results:
        print(asdict(item))
```
