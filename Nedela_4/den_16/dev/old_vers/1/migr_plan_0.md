Гейт считается **зелёным**, если одновременно:
- [ ] baseline зафиксирован (L2 91 / L3 OK / L4 9 / гейт 13+2⚠ с причиной ⚠ README);
- [ ] расхождения с `arch_den_16.md` §2.1 перечислены (привязка к M1–M8);
- [ ] точки внедрения (неизменяемые контракты) зафиксированы;
- [ ] регрессия до изменений подтверждена (код/тесты зелёные);
- [ ] `run.sh` работает; `import mcp` → ModuleNotFoundError зафиксирован (вход M1);
- [ ] `migr_log.md` очищен под den_16; `Проверка.md` под День 16; смоуки den_15
      архивированы; гейт после архивации — без новых красных.

`migr_plan_1.md`.
**Красный** → карточка ошибки `dev/logs_reports/errors/error_<ts>.md`, этап M0 открыт.
