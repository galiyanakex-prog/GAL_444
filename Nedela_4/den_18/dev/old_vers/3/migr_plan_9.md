## 1. Шаги этапа

### Шаг 9.1 — Живой REPL
```bash
PY="../../.venv/bin/python"
printf 'найди город Москва\n/exit\n' | timeout 120 $PY Kod.py --user w16live --mcp
```
(ключ `API_KEY` — из `.env`; endpoint — `MCP_WEATHER_URL` или дефолт).
**Ожидаемо:** подключение READY; в ответе агента — Москва и/или координаты
(55.75…, 37.61…); в логе — след вызова `mcp.weather.search_locations`.

### Шаг 9.2 — Живой `--mcp-probe`
`timeout 60 $PY Kod.py --mcp-probe` → 3 реальных тула, exit 0.

### Шаг 9.3 — Зафиксировать доказательства
- Транскрипт REPL, `Den_log.md` (фрагмент), `tool_audit.jsonl`, `catalog.json` →
  `dev/logs_reports/stages/`.
- Проверить: `TaskStage` не изменился; `transition_log` без записей от вызовов;
  сырые данные не в память.

### Шаг 9.4 — Устранить шероховатости
- Любой сбой (сеть/LLM/схема) → точечный фикс; повторить прогон.
- Если провайдер не поддержал нативный tool_calls — проверить работу fallback-протокола.
