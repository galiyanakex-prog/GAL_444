## 1. Шаги этапа

### Шаг 5.1 — DI при `--mcp` (`Kod.py::build_agent`) — проверка
- При `mcp_enabled`: `ToolPolicy`, `ToolExecutor` (с `gateway`, `registry`, `store`,
  `checker`); `agent.tool_executor = executor`; доставка включает `tools`; задан
  `ToolPromptPolicy` (лимиты) — **уже реализовано в Ревизии 2**, проверить без правок.
- `catalog.refresh()` при старте (`--mcp`) — каталог готов к tool-use (реальный discovery
  к серверу задания); при недоступности — деградация, REPL жив.
- Endpoint сервера задания берётся из env `MCP_SERVER_URL` (иначе дефолт `config.py`).

### Шаг 5.2 — Ручной вызов `/mcp call`
- `/mcp call mcp.time.get_time {"timezone_name":"Asia/Tokyo"}` → результат (ISO 8601).
- Обновить `/help` и строку команд в README — **только если** требуется (в M6).

### Шаг 5.3 — Совместимость
- Без `--mcp`: `agent.tool_executor = None`, каталог не строится, поведение = `den_15`.
- `/mcp`-команды без `--mcp` — прежнее сообщение «MCP-слой выключен».

### Шаг 5.4 — Проверка
- `--mcp --mock`: намерение «который час в Москве?» → тул (fake) → ответ;
- `/mcp call mcp.time.get_time {"timezone_name":"Asia/Tokyo"}` (fake) → результат;
- без `--mcp` — регрессия.
