## 1. Шаги этапа

### Шаг 3.1 — Ручной вызов через `/mcp call`
`$PY Kod.py --user w17 --mcp` →
`/mcp call mcp.time.get_time {"timezone_name":"Europe/Moscow"}`.
**Ожидаемо:** строка ISO 8601 (`2026-09-27T11:33:00+03:00`), `status=succeeded`.

### Шаг 3.2 — Проверка дефолта
`/mcp call mcp.time.get_time {}` → время в `UTC` (default `UTC` из схемы).

### Шаг 3.3 — Прохождение через `ToolExecutor`
- Убедиться, что вызов идёт через `ToolExecutor` (policy → gateway → `ToolExecutionResult`
  → аудит `tool_audit.jsonl`); запись `succeeded` присутствует.
- Проверить: `TaskStage` не изменился; `transition_log` без записей от вызова.

### Шаг 3.4 — Зафиксировать факты
Реальный вывод вызова (ISO 8601) → в `migr_log.md` M3.
