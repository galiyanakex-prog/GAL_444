- [ ] `README.md` существует, непустой, содержит раздел модели памяти и раздел
      «Контролируемые переходы состояний» (гейт-проверки [2], [7] — зелёные);
- [ ] формулировки README/Проверки соответствуют коду (grep-сверка имён);
- [ ] `Проверка.md` — 35 критериев, воспроизводимых по тексту;
- [ ] `scen_1.md` описывает День 15;
- [ ] гейт **15 из 15**; L2 0 FAIL; L4 9/9; L3 OK — без живого ключа.

**Зелёный** → запись M6 в `migr_log.md` (✅) → **перечитать `migr_plan.md`** →
создать `migr_plan_7.md`.
**Красный** → карточка ошибки, этап M6 открыт.
