### 3.2 Флаги запуска
`--user <id>` (идентификация ДО загрузки памяти, п.6), `--deliver <слои>` (набор по
умолчанию), `--mock` (MockClient, без живого ключа), `--log` (лог-файл, default
`Den_11_log.md`), `--memory-dir` (корень users/, default `BASE_DIR/users`),
`--max-tokens`, `--token-log` (CSV, default `den_11_tokens.csv`),
`--price-in`/`--price-out` (default из Step-3.5-Flash_params.md), `--fresh`
(не загружать прошлое состояние). Все пути привязываются к `BASE_DIR`.

### 3.3 Журнал маршрутизации (п.4)
Лог-файл должен содержать записи вида `[Память] layer ← … → путь` при каждом
`remember`, чтобы «в логе виден тип памяти при записи». Подсветка в консоли:
выбранный режим доставки и (при --mock) заглушка.
