## Подшаги этапа

### Подшаг 5.1 — Команды `/plan`, `/step`, `/run`
- Цель: обработчики в REPL-секции: `/plan <цель>` → `agent.start_task` + первый проход
  (planning: LLM строит steps); `/step` → `step_task()` + печать снимка (этап, шаг N/M,
  expected_action, последний result); `/run` → `run_to_end()` + печать маршрута переходов.
  Без активной задачи `/step`, `/run` → подсказка «сначала /plan <цель>».
- Прочитать: `Kod.py` (секция команд — стиль обработчиков `/task`, `/deliver`).
- Изменить/создать: `Kod.py` — три обработчика в порядке существующей if-цепочки.
- Проверка: `py_compile`; CLI-smoke (`--mock --memory-dir .tmp`): echo-пайп
  «/plan Тест», «/step», «/run», «/exit» — EXIT 0, в выводе снимки состояния.
- Запись в журнал: 5.1.
- Объём: ~80 строк чтения, ~45 строк правки.
- Кандидат на батч: да (с 5.2 — один файл, одна секция).

### Подшаг 5.2 — Команды `/pause`, `/resume`, `/task retry`
- Цель: `/pause` → `agent.pause()` + печать previous_stage; `/resume` → `agent.resume()` +
  печать «продолжение: этап X, шаг N/M, ожидаемое действие …»; `/task retry` — ветка в
  обработчике `/task` → `agent.retry_task()`.
- Прочитать: `Kod.py` (обработчик `/task`).
- Изменить/создать: `Kod.py` — два обработчика + ветка retry.
- Проверка: `py_compile`; CLI-smoke: «/plan Тест», «/step», «/pause», «/resume», «/run»,
  «/exit» — после resume шаг не повторён (в выводе шаг N, а не 0).
- Запись в журнал: 5.2.
- Объём: ~40 строк чтения, ~35 строк правки.
- Кандидат на батч: да (с 5.1).

### Подшаг 5.3 — Расширение `/state` + `/help` + стартовая печать + `--fresh`
- Цель: `/state` печатает снимок TaskState (этап, шаг N/M + текст шага, expected_action,
  previous_stage, error, число results) + карту разрешённых переходов (как сейчас);
  `/help` и стартовая строка «Команды: …» дополнены новыми командами; `--fresh`
  дополнительно игнорирует `task_state.json` (старт с PLANNING).
- Прочитать: `Kod.py` (`show_state()`, `print_help()`, обработка `--fresh`).
- Изменить/создать: `Kod.py` — правки трёх мест.
- Проверка: `py_compile`; CLI-smoke: «/state» до и после «/plan» — разные снимки.
- Запись в журнал: 5.3.
- Объём: ~60 строк чтения, ~40 строк правки.
- Кандидат на батч: нет (зависит от 5.1–5.2 семантически; правки мелкие — можно с ними,
  если контекст позволяет).
